01 — THE BEGINNING

Where JavaScript Was Born: A Story of Ten Days That Changed the Web

Every great technology has a story behind its creation. Some take years of research, while others begin with a brilliant idea and a race against time. JavaScript has one such fascinating story.

The Person Behind JavaScript

JavaScript was created by Brendan Eich, an American computer programmer, while working at Netscape Communications in 1995.

At that time, websites were mostly static. HTML provided structure, and CSS controlled appearance, but developers needed a way to make web pages respond to user actions.

Netscape wanted a lightweight scripting language that could work directly inside the browser. The idea was to make websites more interactive by allowing them to respond to clicks, validate forms and perform other dynamic tasks.

The Ten-Day Challenge

One of the most fascinating facts about JavaScript is that its first prototype was created in approximately ten days in May 1995.

Brendan Eich developed this initial prototype while working at Netscape. The language was originally named Mocha. Its first version was only the beginning of a much longer journey of development.

Sometimes, a small beginning can create something that changes the future of technology.

From Mocha to JavaScript

Interestingly, JavaScript did not receive its current name immediately. During its early development, it passed through different names.

  • May 1995 — Mocha: The original prototype developed by Brendan Eich.
  • September 1995 — LiveScript: The language appeared under this name in a beta version of Netscape Navigator 2.0.
  • December 1995 — JavaScript: Netscape and Sun Microsystems announced the JavaScript name.
  • June 1997 — ECMAScript: The first edition of the ECMAScript standard was adopted.

JavaScript and Java: Are They the Same?

Although their names sound similar, JavaScript and Java are two different programming languages. JavaScript received its name during a period when Java was gaining popularity in the technology industry. Their similar names do not mean they are the same language.

How JavaScript Evolved

JavaScript did not remain limited to its original browser-based purpose. Over the years, it developed through new language features, improved browsers, standards and development tools.

Today, JavaScript helps developers create interactive websites, dynamic user interfaces and web applications. It is also used for server-side development.

From a ten-day prototype to a language used across the modern web — JavaScript has an extraordinary story.

A New Chapter Begins

Discovering the history of JavaScript gives me a better understanding of how this language entered the world of web development.

Now that we know who created it, why it was developed and how it evolved, it is time to understand the language itself.

01 — MY FIRST STEPS

How Do We Begin Writing JavaScript?

After understanding how HTML creates the structure of a webpage and CSS makes that structure attractive, I was ready to explore another important part of web development: JavaScript.

At the beginning, one question naturally came to my mind: Where do we actually write JavaScript, and how does a browser understand it?

Before writing complex programs, I needed to understand the basic syntax, the script tag, and the different ways JavaScript can display information.

1. What Is JavaScript Syntax?

Syntax means the set of rules that tells us how to write instructions in a programming language. Just as English follows grammar rules to form meaningful sentences, JavaScript follows its own syntax to create instructions that a browser can understand and execute.

For example, if I want JavaScript to display a simple message, I can write:

JavaScript — First Statement
console.log("Hello, JavaScript!");

Here, JavaScript reads the instruction and sends the message to the browser's developer console.

Every symbol has a purpose. Parentheses hold the information passed to a function, quotation marks represent text, and the semicolon marks the end of the statement.

2. Why Do We Use the Script Tag?

HTML has different tags for different purposes. For example, the <h1> tag creates a heading, while the <p> tag creates a paragraph.

Similarly, HTML provides the <script> tag to include JavaScript code in an HTML document or connect an external JavaScript file.

The script tag is not a JavaScript programming command. It is an HTML element that tells the browser where JavaScript code is included.

Method A: Internal JavaScript

We can write JavaScript directly inside an HTML document by placing it between opening and closing script tags.

HTML + Internal JavaScript
<!DOCTYPE html>
<html>
<head>
    <title>My First JavaScript Page</title>
</head>

<body>

    <h1>Welcome to My Webpage</h1>

    <script>
        console.log("Hello, JavaScript!");
    </script>

</body>
</html>

In this example, the browser reads the HTML structure and encounters the script element. It then processes the JavaScript code inside it.

Method B: External JavaScript

Another way is to create a separate JavaScript file. This approach keeps our HTML structure and JavaScript logic organised in different files.

First, create an HTML file named index.html:

index.html
<!DOCTYPE html>
<html>
<head>
    <title>External JavaScript</title>
</head>

<body>

    <h1>Learning External JavaScript</h1>

    <script src="script.js"></script>

</body>
</html>

Now create another file named script.js in the same folder:

script.js
console.log("JavaScript is connected successfully!");

The src attribute provides the path to our external JavaScript file. When the browser encounters this script element, it loads and executes the referenced file.

External JavaScript makes code easier to maintain, reuse and organise, especially when a project contains multiple pages and programming instructions.

3. Where Should We Place the Script Tag?

While working with HTML and JavaScript, I also learned that the position of a script can affect when it runs.

  • Inside the head: A normal script in the head can execute before the browser has finished reading the page body.
  • Before the closing body tag: A common beginner approach is to place the script near the end of the body so the HTML elements are already parsed before the script runs.
  • Using defer: An external script with the defer attribute downloads while HTML is being parsed and executes after HTML parsing is complete.
External Script Using defer
<head>
    <script src="script.js" defer></script>
</head>

The defer attribute is particularly useful when our JavaScript needs to access HTML elements that appear later in the document.

4. How Can We Display JavaScript Output?

After writing our first JavaScript instructions, the next question is how to see their results. JavaScript provides different ways to display information, depending on what we want to achieve.

I started understanding these methods by using the same simple message in different ways.

Method 1: innerHTML

The innerHTML property allows us to read or change the HTML content inside an element.

HTML
<h2 id="message">Old Message</h2>
JavaScript
document.getElementById("message").innerHTML =
    "Hello! Welcome to JavaScript.";

Here, JavaScript finds the element with the ID message and replaces its existing HTML content with our new message.

This is useful when we want to update webpage content dynamically. However, innerHTML interprets supplied content as HTML, so untrusted user input should not be inserted into it. For plain text, textContent is generally the safer choice.

Method 2: document.write()

The document.write() method writes content directly into an HTML document.

JavaScript
document.write("Hello from JavaScript!");

This method can be useful for demonstrating how JavaScript writes content into a document, but it is not recommended for modern webpage development.

If document.write() is called after a page has finished loading, it can replace the entire document. That is why we should understand it as a learning example rather than a normal method for updating webpages.

Method 3: window.alert()

The alert() method displays a message in a browser dialog box. It is useful when we want to show a simple message that requires the user to acknowledge it.

JavaScript
window.alert("Welcome to my JavaScript journey!");

// Short form:
alert("Hello!");

The browser displays the message in a pop-up dialog. The user must close the dialog before continuing with normal interaction on that page.

Method 4: console.log()

The console.log() method displays information in the browser's developer console. It is one of the most useful methods for learning, testing and debugging JavaScript programs.

JavaScript
console.log("My first JavaScript program");

console.log(100);

console.log(10 + 20);

To see the output, open the browser's developer tools and select the Console tab. In most desktop browsers, you can press F12 to open developer tools.

5. Comparing the Different Output Methods

  • innerHTML: Changes the HTML content inside an existing element.
  • document.write(): Writes content into the document and can replace an already loaded page.
  • alert(): Displays a browser dialog message.
  • console.log(): Displays information in the developer console.

6. My First Learning Realisation

Initially, I thought that displaying a message was simply a matter of remembering a method's name. But after trying different output methods, I began to understand that each method has its own purpose.

A message displayed inside a webpage, a browser pop-up and a developer console output are three different experiences. The right method depends on what the program is supposed to achieve.

Don't just learn how to write a method. Understand why it exists, what it does, and where it should be used.

What I Learned in This Chapter

I learned how JavaScript is included in HTML, why the script tag is needed, how external files are connected, and how different output methods display information.

Now that I can write basic JavaScript instructions and observe their results, I am ready to understand what actually happens when a JavaScript program executes.

02 — UNDERSTANDING THE LOGIC

How Does a JavaScript Program Work?

After writing my first JavaScript instructions, I became curious about what actually happens when a program runs. How does JavaScript understand our code? How does it calculate values, process instructions and produce the expected result?

To understand this, I first needed to become familiar with the basic building blocks of a JavaScript program. These building blocks work together to form meaningful instructions.

1. What Is a JavaScript Statement?

A statement is an instruction that tells JavaScript to perform an action. A complete program is generally made up of multiple statements written in a particular order.

For example, imagine that I want to calculate the total price of two products. I can write:

JavaScript — Multiple Statements
let productPrice = 500;
let deliveryCharge = 50;

let totalPrice = productPrice + deliveryCharge;

console.log(totalPrice);

Here, each instruction performs a particular task. First, we store the product price, then the delivery charge, calculate their total and finally display the result.

JavaScript generally processes these statements in sequence, although functions, conditions, loops and asynchronous operations can change the flow of execution.

2. What Are the Building Blocks of a Statement?

A JavaScript statement can contain different elements. Understanding these elements helps us read and write code more confidently.

A. Values

Values are the basic pieces of information used in JavaScript. They can be numbers, text, Boolean values and many other types of data.

JavaScript — Different Values
100
"Hello World"
true
false
null
undefined

For example, 100 is a number, "Hello World" is a string, and true or false represents a Boolean value.

B. Variables

Variables are named containers that allow us to store and access information in a program.

JavaScript — Storing a Value
let studentName = "Pooja";
let studentAge = 22;

Here, studentName and studentAge are variable names. The values assigned to them can be used later in our program.

C. Operators

Operators are symbols or keywords that perform operations on values and variables.

JavaScript — Operators
let result = 10 + 20;

The plus (+) operator adds two numbers, and the assignment (=) operator assigns the resulting value to the variable.

D. Expressions

An expression is a combination of values, variables, operators or function calls that produces a value.

JavaScript — Expressions
10 + 20

price * quantity

studentAge >= 18

The first expression produces 30. The second calculates a product total, and the third produces a Boolean result: true or false.

A statement can contain one or more expressions. For example:

Expression Inside a Statement
let total = 10 + 20;

The expression 10 + 20 produces a value, while the complete statement stores that value in the variable total.

E. Keywords

Keywords are reserved words that have special meanings in JavaScript. They are used to define programming instructions and structures.

JavaScript — Common Keywords
let
const
var
if
else
for
while
function
return
class

For example, let declares a variable, if introduces a conditional statement, and function defines a function.

We cannot use reserved keywords as ordinary variable names.

F. Comments

Comments are notes written inside source code to explain its purpose. JavaScript ignores comments during normal program execution.

JavaScript supports two common types of comments.

JavaScript — Single-Line Comment
// This is a single-line comment

let price = 500;
JavaScript — Multi-Line Comment
/*
   This is a multi-line comment.
   It can contain explanations
   across multiple lines.
*/

let quantity = 3;

Comments are especially helpful when a program becomes larger and we want to understand why a particular instruction was written.

3. What Is the Role of Semicolons?

A semicolon (;) is commonly used to mark the end of a JavaScript statement.

JavaScript — With Semicolons
let firstNumber = 10;
let secondNumber = 20;

let answer = firstNumber + secondNumber;

console.log(answer);

JavaScript also has a feature called Automatic Semicolon Insertion (ASI). It can insert semicolons in certain situations when they are omitted.

However, semicolons are still commonly used because they make statement boundaries clear and help avoid certain unexpected parsing situations.

4. How Does JavaScript Execute a Program?

Writing code and executing code are two different stages. First, we create instructions. Then, the JavaScript engine processes them.

Modern browsers contain JavaScript engines that understand and execute JavaScript code. For example, Chrome uses the V8 JavaScript engine.

At a simplified level, the engine parses the source code, checks its structure, and executes the program. Modern engines also use techniques such as compilation and optimisation to improve performance.

JavaScript — A Small Program
let itemPrice = 200;
let itemQuantity = 4;

let totalBill = itemPrice * itemQuantity;

console.log("Total Bill:", totalBill);

Let's understand what happens when this program runs:

  • Step 1: JavaScript declares itemPrice and stores 200.
  • Step 2: It declares itemQuantity and stores 4.
  • Step 3: It multiplies the two values.
  • Step 4: It stores the result, 800, in totalBill.
  • Step 5: console.log() displays the result in the console.

Expected console output:

Console Output
Total Bill: 800

5. What Is the Difference Between Syntax and Logic Errors?

While learning programming, I realised that not every incorrect result comes from the same kind of mistake. Sometimes the code itself is written incorrectly, while sometimes the code runs but the logic is wrong.

Syntax Error

A syntax error occurs when the code does not follow the language's grammar rules.

Incorrect JavaScript
let studentName = "Pooja;

console.log(studentName);

The closing quotation mark is missing. The JavaScript engine cannot correctly parse this statement.

Logical Error

A logical error happens when the program runs but produces an incorrect result because the instructions do not represent the intended calculation or behaviour.

Incorrect Calculation
let productPrice = 200;
let quantity = 3;

// Wrong operator for the intended calculation
let total = productPrice + quantity;

console.log(total);

The program runs and displays 203, but if we wanted the total price of three products, we should multiply the price by the quantity.

Correct Calculation
let total = productPrice * quantity;

console.log(total); // 600

6. Why Is Understanding Program Execution Important?

Before moving towards variables, conditions, functions and arrays, I wanted to understand one basic thing: JavaScript does not simply display the code we write. It processes instructions according to their structure and execution flow.

Every value, variable, operator and expression plays a role. Even a small punctuation mistake can change how the browser understands an instruction.

A good programmer does not only write instructions. A good programmer understands how those instructions work together to produce a result.

What I Learned in This Chapter

I learned that JavaScript programs are built from statements, values, variables, operators, expressions, keywords and comments. I also understood how a JavaScript engine processes code and why syntax and logical errors are different.

Now that I understand the basic structure of a JavaScript program, I am ready to explore the elements that help us store and organise information.

03 — STORING INFORMATION

What Are Variables, Identifiers and Data Types?

As I started writing JavaScript programs, I realised that almost every practical program needs some information to work with. A shopping application needs product prices, a registration form needs user details, and a calculator needs numbers.

But where does a programming language keep all this information while a program is running? This is where variables come into the picture.

1. What Is a Variable in JavaScript?

A variable is a named binding that allows us to store and access a value in a program. We can use that information later to perform calculations, make decisions or display results.

Think about a simple student registration form. We may need to store a student's name, age and course information.

JavaScript — Creating Variables
let studentName = "Pooja";
let studentAge = 22;
let studentCourse = "BCA";

console.log(studentName);
console.log(studentAge);
console.log(studentCourse);

In this example, we created three variables and assigned different values to them. JavaScript can access these values whenever the program needs them.

We generally create variables using three declaration keywords: var, let and const. We will compare their behaviour in detail in Chapter 07.

2. How Do We Understand Variable Declaration and Assignment?

Before moving forward, I needed to understand the difference between declaring a variable and assigning a value to it.

JavaScript — Declaration
let productPrice;

Here, we have declared a variable named productPrice, but we have not assigned any value to it yet.

JavaScript — Assignment
productPrice = 500;

Now we have assigned the value 500 to the variable. Assignment means giving a variable a particular value.

JavaScript — Declaration and Assignment Together
let productPrice = 500;

We can also update a variable declared with let:

JavaScript — Updating a Value
let productPrice = 500;

productPrice = 750;

console.log(productPrice); // 750

3. What Is an Identifier?

An identifier is the name we give to programming elements such as variables, functions and classes. It helps us identify and refer to a particular element in our code.

For example:

JavaScript — Identifiers
let studentName = "Pooja";
let totalMarks = 450;

function calculateResult() {
    console.log("Calculating result...");
}

Here, studentName, totalMarks and calculateResult are identifiers. They provide meaningful names to the elements used in our program.

4. What Are the Rules for Naming Variables?

While creating identifiers, JavaScript follows certain naming rules. A name may look simple to us, but it must follow the language's syntax.

  • An identifier can contain letters, digits, underscores (_) and dollar signs ($).
  • It cannot begin with a digit.
  • Spaces are not allowed inside identifiers.
  • Reserved JavaScript keywords cannot be used as ordinary identifiers.
  • JavaScript identifiers are case-sensitive.
  • Names should describe the purpose of the variable or function clearly.
Valid and Invalid Identifier Examples
// Valid identifiers

let studentName = "Pooja";
let student_age = 22;
let totalMarks2 = 450;
let $price = 500;
let _count = 10;


// Invalid identifiers

// let 2students = 10;
// let student name = "Pooja";
// let let = 100;

The invalid examples are commented out so that the entire demonstration can still run without syntax errors.

5. Why Should We Use Meaningful Variable Names?

Imagine that I am creating a shopping application. I need to store a product's price and quantity.

Compare these two approaches:

Less Meaningful Names
let a = 500;
let b = 3;
let c = a * b;
Meaningful Names
let productPrice = 500;
let productQuantity = 3;

let totalAmount = productPrice * productQuantity;

Both examples perform the same calculation. However, the second example is much easier to understand because the names explain what each value represents.

A good programming habit is to use descriptive names and follow a consistent naming convention. One commonly used convention in JavaScript is camelCase.

Camel Case Examples
let firstName = "Pooja";
let productQuantity = 5;
let totalShoppingAmount = 2500;

6. What Are Data Types in JavaScript?

After understanding variables, another question came to my mind: if variables store information, does every variable contain the same kind of data?

The answer is no. JavaScript supports different data types because a program may need to work with numbers, text, true or false values, objects and other kinds of information.

JavaScript has seven primitive data types and one broad non-primitive category: objects.

7. What Are Primitive Data Types?

Primitive values represent individual pieces of information. JavaScript has seven primitive types.

A. Number

The Number type represents numeric values, including integers and decimal numbers.

Number Data Type
let productPrice = 500;
let percentage = 85.5;

console.log(typeof productPrice); // number
console.log(typeof percentage);   // number

B. String

A string represents text. We can write strings using single quotes, double quotes or backticks.

String Data Type
let studentName = "Pooja";
let city = 'Amloh';

console.log(typeof studentName); // string
console.log(typeof city);        // string

C. Boolean

A Boolean represents one of two logical values: true or false.

Boolean Data Type
let isRegistered = true;
let isPaymentComplete = false;

console.log(typeof isRegistered); // boolean

For example, a registration application can use a Boolean value to determine whether a user has completed the registration process.

D. Undefined

Undefined means a variable has been declared but has not yet been assigned a value.

Undefined Data Type
let studentEmail;

console.log(studentEmail);        // undefined
console.log(typeof studentEmail); // undefined

E. Null

Null represents the intentional absence of a value. We can assign null when we want to indicate that something currently has no value.

Null Value
let selectedAddress = null;

console.log(selectedAddress);        // null
console.log(typeof selectedAddress); // object

An important JavaScript detail is that typeof null returns "object". This is a long-standing historical behaviour of the language, not an indication that null is actually an object.

F. BigInt

BigInt is used when we need to work with integers larger than the maximum safe integer supported by the Number type.

BigInt Data Type
let largeNumber = 12345678901234567890n;

console.log(largeNumber);
console.log(typeof largeNumber); // bigint

G. Symbol

Symbol creates a unique primitive value. It is commonly used when we need unique property keys or identifiers inside objects.

Symbol Data Type
let firstId = Symbol("id");
let secondId = Symbol("id");

console.log(firstId === secondId); // false

Even though both symbols contain the same description, they represent two different unique values.

8. What Is the Object Data Type?

Objects allow us to group related information together using properties and values.

Imagine that we want to store information about one student. Instead of creating many separate variables, we can organise the details inside one object.

JavaScript — Object
let student = {
    name: "Pooja",
    age: 22,
    course: "BCA",
    isGraduated: true
};

console.log(student.name);
console.log(student.course);

Here, student is an object. Its properties contain related information such as name, age, course and graduation status.

Arrays, functions and many other JavaScript structures are also objects or object-based structures.

9. How Can We Identify a Variable's Data Type?

JavaScript provides the typeof operator to identify the type of a value.

JavaScript — typeof Operator
let name = "Pooja";
let age = 22;
let isStudent = true;

console.log(typeof name);      // string
console.log(typeof age);       // number
console.log(typeof isStudent); // boolean

This is particularly useful when testing programs and checking what kind of information is being stored or received.

10. What Does Dynamically Typed Mean?

JavaScript is a dynamically typed language. This means we do not have to declare a variable's data type explicitly when creating it.

The type is determined by the value currently assigned to the variable.

JavaScript — Dynamic Typing
let information = "Learning JavaScript";

console.log(typeof information); // string

information = 100;

console.log(typeof information); // number

information = true;

console.log(typeof information); // boolean

Notice that the same variable can hold different types of values at different times. This is one of the important characteristics of JavaScript.

11. My Learning Experience: Understanding Names and Values

In the beginning, I sometimes mixed up variable names, values and data types. I wanted to understand every concept quickly, but the better approach was to create small examples and observe what JavaScript actually stored.

For example, storing a person's age, storing their name and checking whether they are registered are three different situations. Each requires a different kind of value.

Once I started creating my own real-world examples, the purpose of variables and data types became much easier to understand.

Give every variable a meaningful name, understand the value it stores, and always know what kind of information your program is working with.

I learned how to declare variables, assign and update values, construct meaningful identifiers, follow naming rules and identify JavaScript data types.

I also discovered why JavaScript is called a dynamically typed language and how objects help us organise related information.

04 — WORKING WITH VALUES

How Do Expressions and Operators Work?

After learning about variables and data types, I wanted to understand how JavaScript actually works with the values stored inside them.

For example, if I have a product price and its quantity, how can I calculate the total amount? If I have two numbers, how can I compare them? And how can a program decide whether a particular condition is true or false?

This is where expressions and operators become important.

1. What Is an Operator?

An operator is a special symbol or keyword that performs an operation on one or more values. These values are called operands.

For example:

JavaScript — Operators and Operands
let result = 10 + 5;

In this example:

  • 10 is the first operand.
  • + is the addition operator.
  • 5 is the second operand.
  • 10 + 5 is an expression.

JavaScript evaluates the expression and produces the result 15, which is assigned to the variable result.

2. What Is an Expression?

An expression is a combination of values, variables and operators that JavaScript can evaluate to produce a value.

JavaScript — Different Expressions
10 + 20

price * quantity

age >= 18

isLoggedIn && hasPermission

Each of these expressions produces a value when evaluated. Depending on the expression, that value may be a number, Boolean or another type.

We can also store the result of an expression inside a variable.

JavaScript — Storing an Expression Result
let price = 500;
let quantity = 3;

let totalAmount = price * quantity;

console.log(totalAmount); // 1500

3. What Are Arithmetic Operators?

Arithmetic operators are used to perform mathematical calculations. They are useful whenever a program needs addition, subtraction, multiplication, division or other numeric operations.

JavaScript — Arithmetic Operators
let a = 20;
let b = 6;

console.log(a + b);  // 26  Addition
console.log(a - b);  // 14  Subtraction
console.log(a * b);  // 120 Multiplication
console.log(a / b);  // 3.333... Division
console.log(a % b);  // 2   Remainder
console.log(a ** b); // 64000000 Exponentiation

The remainder operator (%) returns the remainder after division. The exponentiation operator (**) raises one number to the power of another.

For example, 20 % 6 gives 2 because 6 goes into 20 three times, leaving a remainder of 2.

4. What Is the Increment and Decrement Operator?

Sometimes we need to increase or decrease a variable's numeric value by one. JavaScript provides two operators for this purpose.

  • ++ Increment: increases a value by 1.
  • -- Decrement: decreases a value by 1.
JavaScript — Increment and Decrement
let visitors = 10;

visitors++;

console.log(visitors); // 11

visitors--;

console.log(visitors); // 10

We can write these operators before or after the variable. This introduces the difference between prefix and postfix operations.

JavaScript — Prefix and Postfix
let number = 5;

console.log(number++); // 5
console.log(number);   // 6

let anotherNumber = 5;

console.log(++anotherNumber); // 6
console.log(anotherNumber);   // 6

In postfix (number++), the current value is used first and then increased. In prefix (++number), the value is increased first and then used.

5. What Are Assignment Operators?

Assignment operators are used to assign values to variables. We have already used the simple assignment operator (=).

JavaScript also provides compound assignment operators that combine an operation with assignment.

JavaScript — Assignment Operators
let total = 100;

total += 20; // total = total + 20
console.log(total); // 120

total -= 10; // total = total - 10
console.log(total); // 110

total *= 2;  // total = total * 2
console.log(total); // 220

total /= 2;  // total = total / 2
console.log(total); // 110

total %= 30; // total = total % 30
console.log(total); // 20

These operators make code shorter and easier to write when we need to update an existing variable.

6. What Are Comparison Operators?

Comparison operators compare two values and produce a Boolean result: true or false.

Imagine that we are creating an online shopping application. We may need to check whether a product is available, whether a price is within a budget or whether a user is old enough to register.

JavaScript — Comparison Operators
let price = 500;
let budget = 1000;

console.log(price > budget);  // false
console.log(price < budget);  // true
console.log(price >= 500);    // true
console.log(price <= 300);    // false
console.log(price === 500);   // true
console.log(price !== 100);   // true

One important point I learned here was the difference between == and ===.

JavaScript — Loose and Strict Equality
console.log(5 == "5");  // true

console.log(5 === "5"); // false

The == operator compares values after allowing type conversion in certain situations. The === operator checks both value and type without performing that implicit conversion.

In most everyday JavaScript code, strict equality (===) is preferred because it makes comparisons more predictable.

7. What Are Logical Operators?

Logical operators help us combine or reverse conditions. They are especially useful when a program needs to check more than one condition.

JavaScript provides three main logical operators:

  • && (AND) — both conditions must be truthy.
  • || (OR) — at least one condition must be truthy.
  • ! (NOT) — reverses a value's truthiness.
JavaScript — Logical Operators
let age = 22;
let hasID = true;

console.log(age >= 18 && hasID); // true

console.log(age >= 18 || hasID); // true

console.log(!hasID); // false

For example, an application might allow a user to enter a restricted area only when they meet the age requirement AND have a valid ID.

An important detail: logical operators work with truthy and falsy values and can return one of their original operands, not necessarily true or false. They also use short-circuit evaluation.

8. What Is the Ternary Operator?

The ternary operator is a shorter way to write a simple conditional expression. It uses three parts: a condition, a value for the true case, and a value for the false case.

JavaScript — Ternary Operator
let age = 20;

let result = age >= 18
    ? "Eligible to register"
    : "Not eligible to register";

console.log(result);

Here, JavaScript checks the condition age >= 18. If it is true, the first message is selected. Otherwise, the second message is selected.

We will explore conditional statements such as if, else and switch in the next chapter.

9. What Is the typeof Operator?

We already used typeof in the previous chapter to identify data types. It is also an operator that returns a string describing the type of a value.

JavaScript — typeof
let username = "Pooja";
let marks = 90;
let isActive = true;

console.log(typeof username); // string
console.log(typeof marks);    // number
console.log(typeof isActive); // boolean

10. What Is the Operator Precedence?

While working with multiple operators in one expression, we need to understand which operation JavaScript performs first.

This order is called operator precedence. For example, multiplication is evaluated before addition in a normal arithmetic expression.

JavaScript — Operator Precedence
let result = 10 + 5 * 2;

console.log(result); // 20

JavaScript multiplies 5 by 2 first, giving 10, and then adds 10. That is why the result is 20.

If we want addition to happen first, we can use parentheses.

JavaScript — Using Parentheses
let result = (10 + 5) * 2;

console.log(result); // 30

Parentheses make the intended order clearer. They are especially useful when expressions become more complex.

05 — MAKING DECISIONS

How Does JavaScript Make Decisions?

When I started learning programming, I realised that writing instructions in sequence was not enough to build a useful application.

A program also needs to respond differently depending on the information it receives. For example, a login page should not display the same message for every password entered by a user.

It must check the entered information and then decide what action to perform. JavaScript uses conditional statements to handle these situations.

1. What Are Conditional Statements?

Conditional statements allow JavaScript to execute different blocks of code depending on whether a particular condition evaluates to true or false.

Think about a simple situation: if a student's marks are 40 or above, the student passes. Otherwise, the student does not pass.

JavaScript — A Simple Condition
let marks = 65;

if (marks >= 40) {
    console.log("You passed!");
}

Here, JavaScript checks whether marks are greater than or equal to 40. Since the condition is true, the message is displayed.

2. How Does the if Statement Work?

The if statement executes a block of code only when its condition evaluates to true.

Its basic syntax looks like this:

JavaScript — if Syntax
if (condition) {
    // Code runs when condition is true
}

Let's understand it with a practical example.

JavaScript — Checking Login Status
let isLoggedIn = true;

if (isLoggedIn) {
    console.log("Welcome back!");
}

Because isLoggedIn contains true, JavaScript executes the instructions inside the if block.

3. What Is the if...else Statement?

Sometimes a program needs to perform one action when a condition is true and another action when it is false.

For these situations, we use if...else.

JavaScript — if...else Syntax
if (condition) {
    // Runs when condition is true
} else {
    // Runs when condition is false
}

Let's return to our student marks example.

JavaScript — Pass or Fail
let marks = 32;

if (marks >= 40) {
    console.log("You passed!");
} else {
    console.log("You did not pass.");
}

Here, the condition is false because 32 is less than 40. Therefore, JavaScript executes the else block.

4. What Is the if...else if...else Statement?

What if we have more than two possible situations? For example, a student may receive different grades depending on their marks.

We can use if...else if...else to check multiple conditions in sequence.

JavaScript — Multiple Conditions
let marks = 82;

if (marks >= 90) {
    console.log("Grade A+");
} else if (marks >= 80) {
    console.log("Grade A");
} else if (marks >= 70) {
    console.log("Grade B");
} else if (marks >= 40) {
    console.log("Grade C");
} else {
    console.log("Fail");
}

The result is Grade A because marks are 82. JavaScript checks conditions from top to bottom and executes the first matching block.

This is why the order of conditions matters. If we placed marks >= 40 first, a student with 82 marks would match that condition immediately, and the later grade conditions would never be checked.

5. What Are Nested if Statements?

A nested if statement means placing one if statement inside another if or else block. It is useful when one decision depends on another decision.

Imagine that a website allows a registered user to access a dashboard only after checking whether their account is active.

JavaScript — Nested if
let isRegistered = true;
let isAccountActive = true;

if (isRegistered) {

    if (isAccountActive) {
        console.log("Access granted!");
    } else {
        console.log("Your account is inactive.");
    }

} else {
    console.log("Please register first.");
}

First, JavaScript checks registration. If the user is registered, it checks the account status. This creates a decision inside another decision.

6. What Is the switch Statement?

When we need to compare one expression against several possible values, the switch statement can make our code easier to organise.

For example, imagine that we are creating a simple menu system with different options.

JavaScript — switch Syntax
switch (expression) {

    case value1:
        // Instructions
        break;

    case value2:
        // Instructions
        break;

    default:
        // Instructions when no case matches
}

Let's use it in a practical example.

JavaScript — Menu Selection
let option = 2;

    case 1:
        console.log("View Profile");
        break;

    case 2:
        console.log("Open Dashboard");
        break;

    case 3:
        console.log("View Settings");
        break;

    default:
        console.log("Invalid Option");
}

Since option is 2, JavaScript executes the second case and displays Open Dashboard.

7. Why Do We Use the break Keyword?

The break keyword tells JavaScript to exit the switch statement after executing a matching case.

Without break, JavaScript may continue executing the statements in the following cases. This behaviour is called fall-through.

JavaScript — Understanding Fall-through
let day = 1;

switch (day) {

    case 1:
        console.log("Monday");

    case 2:
        console.log("Tuesday");

    default:
        console.log("Another day");
}

The output is:

Console Output
Monday
Tuesday
Another day

Because there is no break, execution continues into the following cases.

In normal menu-style switches, we usually add break after each case to avoid this behaviour. Sometimes fall-through is intentional, but it should be used carefully.

8. What Is the default Case?

The default case is executed when none of the specified case values matches the switch expression.

JavaScript — default Case
let option = 5;

switch (option) {

    case 1:
        console.log("Home");
        break;

    case 2:
        console.log("About");
        break;

    default:
        console.log("Please select a valid option.");
}

Here, option is 5, and no case matches it. Therefore, JavaScript executes default.

9. What Is the Difference Between if...else and switch?

Both are used to control the flow of a program, but they are useful in different situations.

Using if...else
let temperature = 35;

if (temperature > 30) {
    console.log("It is hot.");
} else {
    console.log("It is not too hot.");
}
Using switch
let weather = "sunny";

    case "sunny":
        console.log("Enjoy the sunshine!");
        break;

    case "rainy":
        console.log("Carry an umbrella.");
        break;

    default:
        console.log("Check the weather.");
}

We generally use if...else when checking ranges, comparisons or complex conditions. A switch statement is useful when comparing one expression against several specific values.

10. What Are Truthy and Falsy Values?

JavaScript does not require every condition to contain only true or false. It can also evaluate other values using their truthiness.

Values that behave like true in a condition are called truthy. Values that behave like false are called falsy.

Some common falsy values are:

0
-0
0n
""
null
undefined
NaN

Most other values are truthy, including empty arrays [] and empty objects {}.

JavaScript — Truthy and Falsy in Conditions

    console.log("Username entered.");
} else {
    console.log("Please enter your username.");
}

Because an empty string is falsy, JavaScript executes the else block.

07 — UNDERSTANDING VARIABLES

What Is the Difference Between var, let and const?

In my previous chapter, I learned how variables store information and how we can update their values. I also discovered that JavaScript provides three main keywords for declaring variables: var, let and const.

At first, these keywords may look similar because all three can be used to declare variables. However, they behave differently when we consider scope, reassignment, redeclaration and hoisting.

Let's understand these differences with small examples instead of simply memorising a table.

1. What Is var?

The var keyword is the older way of declaring variables in JavaScript. It was commonly used before let and const were introduced in ECMAScript 2015 (ES6).

JavaScript — Declaring with var
var studentName = "Pooja";

console.log(studentName); // Pooja

A variable declared with var can be reassigned and redeclared within the same scope.

JavaScript — Reassignment and Redeclaration
var age = 22;

age = 23;

var age = 24;

console.log(age); // 24

Here, we first declared age, then changed its value and declared it again using var. JavaScript allows this behaviour.

2. What Is let?

The let keyword was introduced in ES6. It allows us to declare variables whose values may need to change while a program is running.

JavaScript — Declaring with let
let visitorCount = 10;

visitorCount = 15;

console.log(visitorCount); // 15

Unlike var, let does not allow us to redeclare the same variable in the same scope.

JavaScript — Redeclaration with let
let visitorCount = 10;

// This would cause a SyntaxError:
// let visitorCount = 20;

However, we can declare another variable with the same name inside a different nested block. This is possible because let follows block scope.

3. What Is const?

The const keyword is also used to declare variables in modern JavaScript. It is useful when we do not want to reassign a variable after its initialisation.

JavaScript — Declaring with const
const websiteName = "WebWorldWithPooja";

console.log(websiteName);

A const declaration must receive an initial value when it is declared.

JavaScript — const Requires Initialisation
// Invalid:
// const websiteName;

// Valid:
const websiteName = "CodingBlogs";

We cannot reassign a const variable later.

JavaScript — Reassignment with const
const websiteName = "CodingBlogs";

// This causes a TypeError:
// websiteName = "WebWorld";

4. What Is Scope in JavaScript?

Before comparing these keywords further, we need to understand scope.

Scope determines where a variable or function can be accessed in a program.

JavaScript has different kinds of scope, including global scope, function scope and block scope.

A. Global Scope

A variable declared outside functions and blocks generally has global scope within its relevant JavaScript environment.

JavaScript — Global Variable
let websiteName = "CodingBlogs";

function showWebsite() {
    console.log(websiteName);
}

showWebsite(); // CodingBlogs

The function can access websiteName because it is declared outside the function and is available in its surrounding scope.

B. Function Scope

A variable declared with var inside a function is accessible within that function, but not outside it.

JavaScript — Function Scope
function showMessage() {

    var message = "Hello JavaScript";

    console.log(message);
}

showMessage();

// This would cause an error:
// console.log(message);

The variable message belongs to the function showMessage. It cannot be accessed from outside that function.

C. Block Scope

A block is a section of code enclosed by curly braces. Variables declared with let and const inside a block are available only within that block and its nested scopes.

JavaScript — Block Scope with let
if (true) {

    let studentName = "Pooja";

    console.log(studentName);
}

// This would cause an error:
// console.log(studentName);

The variable studentName exists inside the if block. Once we try to access it outside that block, JavaScript reports an error.

The same block-scoping rule applies to const.

5. How Does var Behave Inside a Block?

Here is an important difference between var and let or const.

JavaScript — var Is Not Block Scoped
if (true) {

    var message = "Hello from inside the block";

}

console.log(message);

This works because var is not restricted to the nearest block. It is scoped to the containing function or global scope.

If the same example used let or const, accessing message outside the block would cause a ReferenceError.

6. What Is Hoisting in JavaScript?

Hoisting is JavaScript's behaviour of processing declarations before executing the code in their surrounding scope.

It is important to understand that hoisting does not mean every variable is immediately available with its assigned value.

A. Hoisting with var

JavaScript — var Hoisting
console.log(userName); // undefined

var userName = "Pooja";

JavaScript processes the var declaration before executing the code. The variable is initialised with undefined, so accessing it before its assignment does not produce a ReferenceError.

B. Hoisting with let and const

Variables declared with let and const are also hoisted, but they cannot be accessed before their declaration is evaluated.

JavaScript — let and const Before Declaration
// This causes a ReferenceError:
console.log(userAge);

let userAge = 22;

The same restriction applies to const. The period between entering the scope and evaluating the declaration is called the Temporal Dead Zone (TDZ).

The safest habit is to declare variables before using them, rather than depending on hoisting behaviour.

7. Can We Change an Object Declared with const?

This was one of the most interesting differences I discovered. Many beginners think that const makes every part of a variable completely unchangeable. But that is not exactly how JavaScript works.

With objects and arrays, const prevents us from reassigning the variable to another value. It does not automatically make the contents immutable.

JavaScript — Updating an Object Property
const student = {
    name: "Pooja",
    age: 22
};

student.age = 23;

console.log(student.age); // 23

We can update the age property because we are modifying the existing object, not reassigning the student variable.

However, assigning an entirely new object to student is not allowed.

JavaScript — Reassigning a const Object
const student = {
    name: "Pooja"
};

// This causes a TypeError:
// student = { name: "Riya" };

The same principle applies to arrays. We can modify their contents using methods such as push(), but cannot reassign the const variable to another array.

8. Real-World Comparison: Which Keyword Should We Use?

Let's imagine we are building a visitor counter for a website.

JavaScript — A Practical Example
const websiteName = "CodingBlogs";

let visitorCount = 100;

visitorCount++;

console.log(websiteName);
console.log(visitorCount);

Here, the website name is not expected to be reassigned, so const is suitable. The visitor count changes as people visit the website, so let is appropriate.

This is the practical idea behind choosing between let and const.

9. Complete Difference Between var, let and const

Now let's compare all three keywords together.

  • Reassignment: var and let allow reassignment. const does not.
  • Redeclaration in the same scope: var allows it. let and const do not.
  • Scope: var follows function scope or global scope. let and const follow block scope.
  • Hoisting: All three declarations are hoisted, but let and const remain inaccessible in the Temporal Dead Zone until declaration.
  • Initialisation: var and let may be declared without an initial value. const must be initialised when declared.

Initially, I thought that var, let and const were simply three different ways to write the same thing. But after experimenting with their behaviour, I understood why JavaScript provides them separately.

I learned that choosing the right declaration is not just about writing shorter code. It is about controlling where information is accessible and preventing unwanted changes.

In modern JavaScript, a useful general habit is to prefer const when a variable does not need reassignment and use let when its value needs to change. We generally avoid var in new code unless there is a specific reason to use it.

Good code is not only about storing information. It is also about controlling how and where that information can change.

4. Can We Pass a Function as an Argument?

Yes! Since JavaScript treats functions as first-class values, we can pass a function into another function as an argument.

A function that receives or returns another function is often involved in a higher-order function pattern.

JavaScript — Passing a Function
function greetUser() {
    console.log("Welcome, Pooja!");
}

function executeTask(callback) {
    callback();
}

executeTask(greetUser);

Here, greetUser is passed as an argument to executeTask. The receiving parameter callback refers to that function.

Notice that we write greetUser without parentheses. We are passing the function itself, not immediately calling it.

5. What Is an Arrow Function?

Arrow functions were introduced in ECMAScript 2015 (ES6). They provide a shorter syntax for writing function expressions.

An arrow function uses the arrow symbol (=>) between its parameters and function body.

JavaScript — Arrow Function
const greetUser = () => {
    console.log("Hello, welcome!");
};

greetUser();

Instead of writing the function keyword, we use an arrow between the parentheses and the curly braces.

6. How Do We Write Arrow Functions with Parameters?

Arrow functions can also receive parameters, just like regular functions.

JavaScript — Arrow Function with Parameters
const greetUser = (username) => {
    console.log("Hello " + username);
};

greetUser("Pooja");

We can also omit parentheses when an arrow function has exactly one simple parameter.

JavaScript — Single Parameter
const greetUser = username => {
    console.log("Hello " + username);
};

greetUser("Pooja");

However, parentheses are required when there are zero parameters or multiple parameters. Using parentheses consistently can also make code easier to read.

7. What Are Arrow Functions with Multiple Parameters?

When a function needs more than one input, we can include multiple parameters inside parentheses, separated by commas.

JavaScript — Multiple Parameters
const calculateTotal = (price, quantity) => {
    return price * quantity;
};

let total = calculateTotal(500, 3);

console.log(total); // 1500

Here, price and quantity are parameters. The function multiplies them and returns the calculated result.

8. What Is an Implicit Return in Arrow Functions?

One useful feature of arrow functions is that we can write a shorter function body when it contains only one expression.

In this case, JavaScript automatically returns the result of that expression. This is called an implicit return.

JavaScript — Implicit Return
const addNumbers = (a, b) => a + b;

console.log(addNumbers(10, 20)); // 30

We do not need curly braces or an explicit return statement for this concise form.

Compare it with the longer version:

JavaScript — Explicit Return
const addNumbers = (a, b) => {
    return a + b;
};

console.log(addNumbers(10, 20)); // 30

Both examples return the same result. The difference is the way the function body is written.

9. What Happens When We Use Curly Braces in an Arrow Function?

This is an important detail to remember. When we use curly braces to write a normal arrow function body, we must explicitly write return if we want to send a value back.

JavaScript — Missing return
const multiply = (a, b) => {
    a * b;
};

console.log(multiply(5, 4)); // undefined

The function calculates nothing that it returns to the caller. Its result is undefined.

The correct version is:

JavaScript — Correct Explicit Return
const multiply = (a, b) => {
    return a * b;
};

console.log(multiply(5, 4)); // 20

10. Can Arrow Functions Return Objects?

Yes! But there is a small syntax detail. When we want to return an object directly using an implicit return, we need to wrap the object literal in parentheses.

JavaScript — Returning an Object
const createStudent = () => ({
    name: "Pooja",
    course: "BCA"
});

console.log(createStudent());

The parentheses tell JavaScript to interpret the curly braces as an object expression, rather than as the function body.

11. What Is the Difference Between Regular Functions and Arrow Functions?

Arrow functions are not simply shorter replacements for every regular function. They have some important behavioural differences.

  • Syntax: Regular functions use the function keyword. Arrow functions use the arrow symbol (=>).
  • this: Regular functions have their own this value depending on how they are called. Arrow functions inherit this from their surrounding lexical scope.
  • arguments: Regular functions have their own arguments object. Arrow functions do not have their own arguments object.
  • Constructor: Regular constructible functions can be used with new. Arrow functions cannot be used as constructors.
  • Hoisting: Function declarations can generally be called before their declaration. Function expressions and arrow functions assigned to let or const variables cannot be used before those declarations are evaluated.

12. What Is the this Keyword in Arrow Functions?

The this keyword refers to a value determined by the surrounding execution context. Regular functions and arrow functions handle it differently.

A regular function gets its own this value based on how it is called. An arrow function does not create its own this. Instead, it uses the this value from the surrounding lexical scope.

JavaScript — Arrow Function and this
const student = {
    name: "Pooja",

    showName() {
        console.log(this.name);
    }
};

student.showName(); // Pooja

Here, showName is a regular method. When called as student.showName(), this refers to the student object.

We will explore this and object methods further as we learn more about JavaScript.

13. When Should We Use Arrow Functions?

Arrow functions are especially useful for short callbacks, calculations and functions where we want to preserve the surrounding this value.

JavaScript — Arrow Function in a Callback
const numbers = [10, 20, 30];

numbers.forEach(number => {
    console.log(number);
});

Here, forEach() receives an arrow function as its callback. JavaScript executes that callback for each array element.

We will explore array methods and callbacks in much greater detail in the upcoming array chapters.

Sometimes a regular function declaration makes the program easier to understand. In other situations, an arrow function makes a small calculation or callback much cleaner.

My approach became simple: first understand what the function needs to do, then choose the syntax that makes its purpose clear.

Learn the behaviour behind a function before choosing its syntax. A shorter expression is useful only when it remains understandable.

09 — STORING AND ORGANISING DATA

How Do Arrays Store and Organise Data?

While learning variables, I understood that a variable stores a value that we can use throughout our program.

But what if I need to store the names of five students, the prices of ten products or the marks of an entire class?

Creating a separate variable for every value would make the program lengthy and difficult to manage.

JavaScript provides a solution called an Array.

1. What Is an Array in JavaScript?

An array is a special type of object used to store multiple values in a single variable.

Each value inside an array is called an element. Elements are arranged in an ordered sequence and can be accessed using their index positions.

JavaScript — Creating an Array
const studentNames = [
    "Pooja",
    "Aman",
    "Riya",
    "Rahul"
];

console.log(studentNames);

Here, studentNames is one variable that stores four different names inside an array.

2. How Do We Create an Array?

The most common way to create an array is by using square brackets [ ]. We write the elements inside these brackets and separate them with commas.

JavaScript — Array Syntax
const arrayName = [
    value1,
    value2,
    value3
];

We can create an empty array as well.

JavaScript — Empty Array
const products = [];

console.log(products); // []

We can add elements to this array later using array methods.

3. What Are Array Indexes?

Every element in an array has an index. An index represents the position of an element inside the array.

One important thing I learned is that JavaScript array indexes begin at zero, not one.

JavaScript — Understanding Indexes
const fruits = [
    "Apple",
    "Mango",
    "Orange",
    "Banana"
];

console.log(fruits[0]); // Apple
console.log(fruits[1]); // Mango
console.log(fruits[2]); // Orange
console.log(fruits[3]); // Banana

The first element is at index 0, the second at index 1, and so on.

We can visualise the array like this:

Array Index Structure
Index:      0        1         2         3
         +--------+--------+---------+---------+
Value:   | Apple  | Mango  | Orange  | Banana  |
         +--------+--------+---------+---------+

4. How Do We Access Array Elements?

We can access an individual element by writing the array name followed by its index inside square brackets.

JavaScript — Accessing Elements
const colors = ["Red", "Blue", "Green"];

let selectedColor = colors[1];

console.log(selectedColor); // Blue

Here, colors[1] accesses the element at index 1, which is Blue.

We can also use the index to update an existing element.

JavaScript — Updating an Element
const colors = ["Red", "Blue", "Green"];

colors[1] = "Yellow";

console.log(colors);

// ["Red", "Yellow", "Green"]

Notice that we declared the array using const, but we can still change one of its elements. This is because const prevents reassignment of the array variable, not modification of the array's contents.

5. What Is the length Property?

JavaScript provides a useful property called length. It tells us how many elements are currently in an array.

JavaScript — Array Length
const subjects = [
    "HTML",
    "CSS",
    "JavaScript",
    "PHP"
];

console.log(subjects.length); // 4

Remember the difference:

  • Index tells us the position of an element.
  • Length tells us the total number of elements.
  • The last element's index is usually length - 1 for a normal dense array.

6. Can an Array Store Different Data Types?

Yes! JavaScript arrays can contain different types of values in the same array.

JavaScript — Mixed Data Types
const student = [
    "Pooja",
    22,
    true,
    null,
    undefined
];

console.log(student);

This array contains a string, number, boolean, null and undefined value.

Although JavaScript allows mixed data types, using a consistent structure often makes real-world programs easier to understand and maintain.

7. What Are One-Dimensional and Multidimensional Arrays?

Arrays can be organised in different structures depending on how we want to store information.

One-dimensional array: It stores elements in a single sequence.

JavaScript — One-Dimensional Array
const marks = [85, 90, 78, 92];

console.log(marks[0]); // 85

Two-dimensional array: It is an array containing other arrays. We can use it to represent rows and columns of information.

JavaScript — Two-Dimensional Array
const studentMarks = [
    [85, 90, 78],
    [88, 92, 81],
    [75, 86, 89]
];

console.log(studentMarks[0][1]); // 90

Here, studentMarks[0] selects the first inner array, and [1] selects its second element.

JavaScript technically uses nested arrays rather than a separate built-in matrix type.

8. How Do We Find the Position of an Element?

Sometimes we know the value but not its index. JavaScript provides methods such as indexOf() and includes() to help us.

indexOf(): Returns the first index where a value is found. If the value is not present, it returns -1.

JavaScript — indexOf()
const fruits = ["Apple", "Mango", "Orange"];

console.log(fruits.indexOf("Mango")); // 1
console.log(fruits.indexOf("Grapes")); // -1

includes(): Checks whether an array contains a particular value. It returns true or false.

JavaScript — includes()
const fruits = ["Apple", "Mango", "Orange"];

console.log(fruits.includes("Apple")); // true
console.log(fruits.includes("Grapes")); // false

9. How Do We Add and Remove Array Elements?

JavaScript provides several methods for inserting and removing array elements. Let's understand four commonly used methods.

push(): Adds one or more elements at the end of an array.

JavaScript — push()
const fruits = ["Apple", "Mango"];

fruits.push("Orange");

console.log(fruits);

// ["Apple", "Mango", "Orange"]

pop(): Removes the last element from an array and returns it.

JavaScript — pop()
const fruits = ["Apple", "Mango", "Orange"];

let removedFruit = fruits.pop();

console.log(removedFruit); // Orange
console.log(fruits); // ["Apple", "Mango"]

unshift(): Adds one or more elements at the beginning of an array.

JavaScript — unshift()
const fruits = ["Mango", "Orange"];

fruits.unshift("Apple");

console.log(fruits);

// ["Apple", "Mango", "Orange"]

shift(): Removes the first element and returns the removed value.

JavaScript — shift()
const fruits = ["Apple", "Mango", "Orange"];

let removedFruit = fruits.shift();

console.log(removedFruit); // Apple
console.log(fruits); // ["Mango", "Orange"]

10. What Is the Difference Between slice() and splice()?

These two methods look similar in name, but their behaviour is different.

slice(): Returns a selected portion of an array without changing the original array.

JavaScript — slice()
const fruits = [
    "Apple",
    "Mango",
    "Orange",
    "Banana"
];

const selectedFruits = fruits.slice(1, 3);

console.log(selectedFruits);
// ["Mango", "Orange"]

console.log(fruits);
// Original array remains unchanged

The starting index is included, but the ending index is excluded.

splice(): Can remove, replace or insert elements directly into the original array.

JavaScript — splice()
const fruits = [
    "Apple",
    "Mango",
    "Orange",
    "Banana"
];

fruits.splice(1, 1);

console.log(fruits);

// ["Apple", "Orange", "Banana"]

Here, splice(1, 1) starts at index 1 and removes one element.

11. What Is the Difference Between Mutating and Non-Mutating Methods?

While exploring array methods, I realised that some methods change the original array, while others return a new array or value without changing the original.

This distinction is important when we write programs that work with stored data.

  • Mutating methods: push(), pop(), shift(), unshift(), splice(), sort() and reverse().
  • Non-mutating methods: slice(), concat(), includes(), indexOf() and map().

A method's return value also matters. For example, push() returns the new array length, while pop() returns the removed element.

12. How Can We Check Whether a Value Is an Array?

JavaScript provides Array.isArray() to check whether a value is an array.

JavaScript — Array.isArray()
const fruits = ["Apple", "Mango"];
const username = "Pooja";

console.log(Array.isArray(fruits)); // true
console.log(Array.isArray(username)); // false

One interesting point is that typeof returns "object" for arrays. This is why Array.isArray() is the reliable way to identify an array.

10 — ARRAY TRAVERSAL & TRANSFORMATION

How Do We Traverse and Transform Arrays?

In the previous chapter, I learned how arrays store multiple values in a single variable.

But storing values is not enough. In practical programming, we often need to visit every element, perform calculations, search for particular values or create another array from existing data.

This process introduces two important concepts: array traversal and array transformation.

1. What Is Array Traversal?

Array traversal means accessing or visiting array elements one by one, usually to perform some operation on each element.

For example, imagine we have stored the marks of four students. We want to display every student's marks.

JavaScript — Array Example
const marks = [85, 90, 76, 95];

console.log(marks[0]);
console.log(marks[1]);
console.log(marks[2]);
console.log(marks[3]);

This works, but imagine an array containing hundreds of elements. Writing a separate console.log() statement for every element would be inefficient.

That's why JavaScript provides loops and array methods to traverse elements more conveniently.

2. How Do We Traverse an Array Using a for Loop?

A for loop is one of the traditional ways to traverse an array.

It uses three main parts:

  • Initialization: Creates the starting value of the counter.
  • Condition: Checks whether the loop should continue.
  • Update: Changes the counter after each iteration.
JavaScript — Traversing with for Loop
const marks = [85, 90, 76, 95];

for (let i = 0; i < marks.length; i++) {
    console.log(marks[i]);
}

Let's understand what happens:

  • let i = 0 starts the counter at index zero.
  • i < marks.length checks whether the current index is within the array.
  • marks[i] accesses the current element.
  • i++ increases the counter after each iteration.

The loop continues until the condition becomes false.

3. What Is a for...of Loop?

JavaScript also provides a simpler way to access the values of an array using the for...of loop.

JavaScript — for...of Loop
const fruits = ["Apple", "Mango", "Orange"];

for (const fruit of fruits) {
    console.log(fruit);
}

Here, JavaScript gives us each array element directly. We do not need to manage an index counter ourselves.

This makes for...of useful when we simply want to read or process each value.

4. What Is the forEach() Method?

Another way to traverse an array is by using the forEach() method.

It executes a callback function once for each element in the array.

JavaScript — forEach()
const fruits = ["Apple", "Mango", "Orange"];

fruits.forEach(function(fruit) {
    console.log(fruit);
});

We can also write the callback using an arrow function.

JavaScript — forEach() with Arrow Function
const fruits = ["Apple", "Mango", "Orange"];

fruits.forEach(fruit => {
    console.log(fruit);
});

Both examples perform the same task. The second version uses shorter arrow function syntax.

5. What Parameters Does forEach() Receive?

The callback function passed to forEach() can receive three arguments:

  • Element: The current array element.
  • Index: The position of the current element.
  • Array: The original array being traversed.
JavaScript — forEach() Parameters
const subjects = ["HTML", "CSS", "JavaScript"];

subjects.forEach((subject, index, array) => {

    console.log("Subject:", subject);
    console.log("Index:", index);
    console.log("Original Array:", array);

});

We do not have to use all three parameters. We can receive only the information needed for our task.

One important point: forEach() returns undefined. It is generally used when we want to perform an action for each element, rather than create a new array.

6. What Is Array Transformation?

Sometimes we do not just want to visit elements. We want to use existing values to produce a new collection of values.

This process is called array transformation. JavaScript provides the map() method for this purpose.

7. What Is the map() Method?

The map() method creates a new array by applying a callback function to every element of the original array.

It does not change the original array merely by performing the mapping operation.

JavaScript — map()
const numbers = [10, 20, 30, 40];

const doubledNumbers = numbers.map(number => {
    return number * 2;
});

console.log(doubledNumbers);

// [20, 40, 60, 80]

console.log(numbers);

// [10, 20, 30, 40]

Here, map() takes each number, multiplies it by two and places the returned result into a new array.

The original numbers array remains unchanged.

8. What Parameters Does map() Receive?

Like forEach(), the map() callback can receive three arguments:

  • Element: The current value.
  • Index: The current element's position.
  • Array: The original array.
JavaScript — map() Parameters
const prices = [100, 200, 300];

const updatedPrices = prices.map(
    (price, index, array) => {

        console.log("Price:", price);
        console.log("Index:", index);
        console.log("Original Array:", array);

        return price + 50;
    }
);

console.log(updatedPrices);

// [150, 250, 350]

Notice that we use return inside the callback. map() collects each returned value and places it into the new array.

9. What Is Array.prototype.map()?

We often write map() directly after an array variable. But in JavaScript, arrays inherit methods through Array.prototype.

Array.prototype is the prototype object that provides shared methods for array instances.

JavaScript — map() Through Array.prototype
const numbers = [2, 4, 6];

const result = Array.prototype.map.call(
    numbers,
    number => number * 3
);

console.log(result);

// [6, 12, 18]

Here, call() invokes the map method with numbers as its array object.

In everyday programming, we normally write numbers.map(). Understanding Array.prototype simply helps us understand where array methods come from.

10. What Is the filter() Method?

Sometimes we want only selected elements from an array instead of transforming every element.

The filter() method creates a new array containing only those elements for which the callback returns true.

JavaScript — filter()
const marks = [45, 80, 32, 90, 65];

const passedStudents = marks.filter(mark => {
    return mark >= 50;
});

console.log(passedStudents);

// [80, 90, 65]

Here, filter() checks every mark. Values greater than or equal to 50 are included in the new array.

The original marks array remains unchanged.

11. What Is the find() Method?

The find() method searches an array and returns the first element that satisfies a given condition.

JavaScript — find()
const marks = [45, 80, 32, 90, 65];

const firstHighMark = marks.find(mark => {
    return mark >= 80;
});

console.log(firstHighMark); // 80

Unlike filter(), find() returns one matching element, not a new array of all matching elements.

If no element matches the condition, find() returns undefined.

12. What Is the reduce() Method?

Now let's explore another powerful array method: reduce().

The reduce() method processes array elements and combines them into a single accumulated result.

For example, if we have several product prices, we can use reduce() to calculate their total.

JavaScript — reduce()
const prices = [100, 200, 300, 400];

const total = prices.reduce((accumulator, currentValue) => {
    return accumulator + currentValue;
}, 0);

console.log(total); // 1000

Let's understand the two important parameters:

  • Accumulator: Stores the result collected so far.
  • Current Value: Represents the element currently being processed.

The zero at the end is the initial value of the accumulator.

13. How Does reduce() Work Step by Step?

Let's visualise how the total is calculated. Our array contains [100, 200, 300, 400], and the initial accumulator value is 0.

Understanding reduce() Execution
Starting accumulator = 0

Step 1:
0 + 100 = 100

Step 2:
100 + 200 = 300

Step 3:
300 + 300 = 600

Step 4:
600 + 400 = 1000

Final result = 1000

At each step, reduce() uses the returned value as the accumulator for the next iteration.

14. What Other Parameters Can reduce() Receive?

The reduce() callback can receive four arguments:

  • Accumulator: The accumulated result.
  • Current Value: The current element.
  • Current Index: The index of the current element.
  • Array: The original array.
JavaScript — reduce() Parameters
const numbers = [10, 20, 30];

const total = numbers.reduce(
    (accumulator, currentValue, index, array) => {

        console.log("Accumulator:", accumulator);
        console.log("Current Value:", currentValue);
        console.log("Index:", index);
        console.log("Array:", array);

        return accumulator + currentValue;

    },
    0
);

console.log("Total:", total); // 60

We can use only the parameters needed for our calculation. The initial value is optional, but providing it is often clearer and safer.

If we omit the initial value, reduce() starts with the first array element as its accumulator and begins processing from the second element. An empty array without an initial value causes a TypeError.

15. What Is the Difference Between forEach(), map(), filter() and reduce()?

These methods may look similar because they all process array elements, but their purposes and return values are different.

  • forEach(): Executes an operation for every element. Returns undefined.
  • map(): Transforms every element and returns a new array.
  • filter(): Selects matching elements and returns a new array.
  • find(): Returns the first matching element or undefined.
  • reduce(): Combines elements into one accumulated result.

16. A Practical Example: Calculating a Shopping Bill

Let's bring these methods together with a small real-world example.

Imagine a shopping cart containing different product prices. We want to display all prices, find discounted products and calculate the final total.

JavaScript — Shopping Cart Example
const prices = [500, 1200, 300, 1500, 800];

// Display every price
prices.forEach(price => {
    console.log("Product Price:", price);
});

// Create a new array with a 10% discount
const discountedPrices = prices.map(price => {
    return price * 0.90;
});

// Select products costing more than 700
const expensiveProducts = prices.filter(price => {
    return price > 700;
});

// Calculate the total
const total = prices.reduce((sum, price) => {
    return sum + price;
}, 0);

console.log("Discounted Prices:", discountedPrices);
console.log("Expensive Products:", expensiveProducts);
console.log("Total Bill:", total);

This example helped me understand that different methods can work with the same array while performing different tasks.

Initially, I thought I could understand many methods in one day. But I learned that every method has its own purpose, parameters and return behaviour.

My approach is to take one or two methods, create small examples, predict their output and then compare the actual result.

Don't just ask how a method is written. Ask what it receives, what it does, what it returns and whether it changes the original data.

11 — STRINGS & TEXT MANIPULATION

How Do Strings and Template Literals Work?

While learning JavaScript, I realised that many things we see on a website are actually text values: usernames, headings, messages, product names, descriptions and search terms.

JavaScript provides a data type called String to represent and work with text.

1. What Is a String in JavaScript?

A string is a sequence of characters used to represent text. We can write a string using single quotes, double quotes or backticks.

JavaScript — Creating Strings

console.log(city);
console.log(message);

All three examples create string values. The choice of quotation marks depends on how we want to write and use the text.

2. What Is the Difference Between Single, Double and Backtick Quotes?

Single and double quotes are commonly used for ordinary strings. Backticks are used to create template literals, which provide additional features.

JavaScript — Different String Quotes

JavaScript — String length

Here, JavaScript counts the length of the string and returns 10.

JavaScript — Accessing Characters

console.log(language[1]); // a
console.log(language[2]); // v
console.log(language[3]); // a

We can also use charAt() to access a character at a particular position.

JavaScript — charAt()
const language = "JavaScript";

Another useful method is at(), which also supports negative indexes.

JavaScript — at()
const language = "JavaScript";

console.log(language.at(0));  // J
console.log(language.at(-1)); // t

5. How Do We Change the Letter Case of a String?

Sometimes we need to convert text into uppercase or lowercase letters. JavaScript provides two useful methods.

toUpperCase(): Converts letters into uppercase.

JavaScript — toUpperCase()
const username = "pooja vartia";

console.log(username.toUpperCase());

// POOJA VARTIA

toLowerCase(): Converts letters into lowercase.

JavaScript — toLowerCase()
const username = "POOJA VARTIA";

console.log(username.toLowerCase());

// pooja vartia

6. How Do We Remove Extra Spaces from Text?

When users enter information into forms, they may accidentally add spaces before or after their text.

ECMAScript is the language specification that defines the core rules, features and behaviour of JavaScript.

JavaScript is the programming language we write and execute. ECMAScript provides the standard that JavaScript engines follow when implementing the language.

In simple words:

2. A Short History of JavaScript

JavaScript was created by Brendan Eich in 1995 while he was working at Netscape.

1995  - JavaScript was created.

1997  - First ECMAScript specification (ES1).

2009  - ECMAScript 5 (ES5).

2015  - ECMAScript 2015 (ES6).

2016  - Annual ECMAScript releases began.

Today - JavaScript continues to evolve.

The ECMAScript standard is maintained by Ecma International, through its technical committee TC39.

14 — DOM & BOM

How Do the DOM and BOM Work?

While learning HTML and CSS, I understood how to create the structure and appearance of a web page. But I wanted to understand how JavaScript could change that structure, update content and interact with the browser.

This is where two important browser concepts come into the picture: DOM and BOM.

HTML creates the structure, CSS styles it, and JavaScript can make that structure interactive.

1. What Is the DOM?

DOM stands for Document Object Model. It is a programming interface that represents an HTML document as a structured tree of objects called nodes.

When a browser loads an HTML page, it parses the HTML and creates a DOM tree. JavaScript can then access and manipulate this representation of the document.

Let's understand it with a simple HTML example:

HTML Document
<!DOCTYPE html>
<html>
    <head>
        <title>My Website</title>
    </head>

    <body>
        <h1>Welcome to My Website</h1>

        <p>I am learning JavaScript.</p>
    </body>
</html>

The browser represents this document in a tree-like structure. The html element is the root element, and other elements are arranged beneath it.

2. Understanding the DOM Tree Structure

A DOM tree represents the relationship between different parts of an HTML document.

Simplified DOM Tree
Document
   |
   └── html
       |
       ├── head
       |    |
       |    └── title
       |         |
       |         └── "My Website"
       |
       └── body
            |
            ├── h1
            |    |
            |    └── "Welcome to My Website"
            |
            └── p
                 |
                 └── "I am learning JavaScript."

Here, each HTML element becomes an element node, while the text inside elements is represented by text nodes. The document itself is represented by a document node.

We can understand the relationships using some important DOM terms:

  • Parent: An element that contains another node.
  • Child: A node directly contained inside another node.
  • Sibling: Nodes that share the same parent.
  • Ancestor: Any parent higher up in the tree.
  • Descendant: Any node nested inside another node.

3. What Can JavaScript Do with the DOM?

JavaScript can use the DOM to interact with HTML elements. It can:

  • Change text and HTML content.
  • Modify CSS styles.
  • Change HTML attributes.
  • Create new HTML elements.
  • Remove existing elements.
  • Respond to user interactions.

For example, suppose we have a heading in HTML and want JavaScript to change its text.

HTML
<h1 id="heading">Hello World</h1>
JavaScript
document.getElementById("heading").textContent =
    "Welcome to JavaScript!";

JavaScript finds the heading using its ID and changes its text content. The browser then displays the updated heading.

4. What Is the BOM?

BOM stands for Browser Object Model. It refers to browser-provided objects that allow JavaScript to interact with the browser environment beyond the contents of the current HTML document.

For example, JavaScript can use browser objects to:

  • Access the browser window.
  • Read or change the current URL.
  • Move backward or forward through browsing history.
  • Display browser alerts.
  • Work with timers.
  • Access information about the browser environment.

The BOM is a commonly used term for browser-related APIs. Unlike the DOM, it is not one single formal specification with a universally fixed boundary.

5. Understanding the Window Object

The window object represents the browser window or browsing context in which the JavaScript code is running.

In a normal browser page, window is the global object for JavaScript running in that page.

Window Object Example
console.log(window);

console.log(window.innerWidth);

console.log(window.innerHeight);

Here:

  • window.innerWidth: Returns the width of the browser's layout viewport in CSS pixels.
  • window.innerHeight: Returns the height of the browser's layout viewport in CSS pixels.

We can also access some window methods without writing the window prefix because they are available in the global browser scope.

Window Methods
// Both statements open an alert

window.alert("Welcome!");

alert("Hello JavaScript!");

6. Understanding the Document Object

The document object represents the currently loaded HTML document. It provides methods and properties for accessing and changing the page's content.

Document Object Example
console.log(document);

console.log(document.title);

console.log(document.URL);

console.log(document.body);

Notice that document is also available through the window object:

Window and Document Relationship
console.log(window.document);

console.log(document);

// Both refer to the same document object

The document object is our main starting point when we want to select and manipulate HTML elements.

7. What Is the Difference Between DOM and BOM?

Both DOM and BOM help JavaScript interact with the browser, but they focus on different things.

DOM vs BOM
DOM
 |
 |-- Represents the HTML document
 |-- Provides access to HTML elements
 |-- Changes page content
 |-- Modifies element attributes and styles
 |
 |-- Example: document.getElementById()


BOM
 |
 |-- Provides browser-related objects
 |-- Works with browser window information
 |-- Accesses location and history
 |-- Provides timers and browser dialogs
 |
 |-- Example: window.location

A simple way to remember:

  • DOM: Working with the web page and its document structure.
  • BOM: Working with the browser environment.

15 — DOM SELECTION & NAVIGATION

How Do We Find and Navigate HTML Elements?

While learning the DOM, I discovered that JavaScript needs a reference to an HTML element before it can change its content, style or attributes.

For example, if I want to change a heading, JavaScript first needs to locate that heading inside the HTML document. This process is called DOM selection.

After selecting an element, we can also explore its relationship with other elements using DOM navigation.

Before changing an element, learn how to find it. Before navigating the DOM, understand its tree structure.

1. What Is DOM Selection?

DOM selection means finding or selecting HTML elements from a document using JavaScript.

JavaScript provides different methods for selecting elements. Each method works in a slightly different way.

Let's understand them with one HTML example:

HTML Structure
<h1 id="mainHeading">Welcome to My Website</h1>

<p class="description">
    I am learning JavaScript.
</p>

<p class="description">
    I am exploring the DOM.
</p>

<button id="learnButton">Learn More</button>

2. document.getElementById()

The getElementById() method selects an HTML element using its unique ID.

Selecting an Element by ID
let heading = document.getElementById("mainHeading");

console.log(heading);

Here:

  • document refers to the current HTML document.
  • getElementById() is the selection method.
  • "mainHeading" is the ID we want to find.
  • heading stores the selected element reference.

We can now use that reference to change the heading's text.

Changing Heading Content
let heading = document.getElementById("mainHeading");

heading.textContent = "Hello JavaScript!";

Remember that an ID should be unique within an HTML document. If no matching ID exists, getElementById() returns null.

3. document.getElementsByClassName()

The getElementsByClassName() method selects all elements that have a specified class name.

Selecting Elements by Class
let descriptions =
    document.getElementsByClassName("description");

console.log(descriptions);

Unlike getElementById(), this method returns a live HTMLCollection. It can contain multiple matching elements.

We can access individual elements using their index. Remember that indexing starts from zero.

Accessing Selected Elements
let descriptions =
    document.getElementsByClassName("description");

console.log(descriptions[0]);

console.log(descriptions[1]);

We can also use a loop to work with every selected element.

Loop Through an HTMLCollection
let descriptions =
    document.getElementsByClassName("description");

for (let i = 0; i < descriptions.length; i++) {

    descriptions[i].style.color = "blue";

}

4. document.getElementsByTagName()

This method selects elements according to their HTML tag name, such as h1, p, div or button.

Selecting Paragraph Elements
let paragraphs = document.getElementsByTagName("p");

console.log(paragraphs);

It also returns a live HTMLCollection.

Changing All Paragraphs
let paragraphs = document.getElementsByTagName("p");

for (let i = 0; i < paragraphs.length; i++) {

    paragraphs[i].style.fontSize = "18px";

}

5. document.querySelector()

The querySelector() method selects the first element that matches a given CSS selector.

This is useful because we can select elements using IDs, classes, tag names and more complex CSS selectors.

Selecting Different Elements
// Select by ID
let heading = document.querySelector("#mainHeading");

// Select by class
let description = document.querySelector(".description");

// Select by tag
let button = document.querySelector("button");

Notice the symbols:

  • # is used for an ID selector.
  • . is used for a class selector.
  • A tag name such as p selects that element type.

If multiple elements match the selector, querySelector() returns only the first matching element.

6. document.querySelectorAll()

The querySelectorAll() method selects all elements that match a CSS selector.

Selecting All Matching Elements
let descriptions =
    document.querySelectorAll(".description");

console.log(descriptions);

It returns a static NodeList. Unlike a live HTMLCollection, this collection does not automatically update when the document changes.

We can use forEach() to access each selected element.

Using forEach() with NodeList
let descriptions =
    document.querySelectorAll(".description");

descriptions.forEach(function(item) {

    item.style.color = "green";

});

7. Comparing DOM Selection Methods

Quick Comparison
getElementById()
    → Selects one element by ID.

getElementsByClassName()
    → Returns a live HTMLCollection.

getElementsByTagName()
    → Returns a live HTMLCollection.

querySelector()
    → Returns the first CSS selector match.

querySelectorAll()
    → Returns a static NodeList of all matches.

When I compare these methods, I notice that querySelector() and querySelectorAll() are flexible because they allow us to use CSS selector syntax.

8. What Is DOM Navigation?

DOM navigation means moving through the DOM tree to access related elements.

Once we select one element, we may need to find:

  • Its parent element.
  • Its child elements.
  • Its first or last child.
  • Its previous or next sibling.

Let's use the following HTML structure:

DOM Navigation Example
<div id="container">

    <h2>Learning JavaScript</h2>

    <p id="firstPara">First paragraph</p>

    <p id="secondPara">Second paragraph</p>

    <button>Explore</button>

</div>

9. Accessing Parent Elements

The parentElement property gives us the parent element of a selected HTML element.

parentElement
let paragraph = document.getElementById("firstPara");

let parent = paragraph.parentElement;

console.log(parent);

Here, the parent of the paragraph is the div element with the ID container.

We can also use parentNode, which returns the parent node. The difference is that parentNode can represent any kind of node, whereas parentElement returns an element or null.

10. Accessing Child Elements

The children property returns the child elements of a selected element.

children
let container = document.getElementById("container");

console.log(container.children);

In our example, the container has four child elements: h2, first p, second p and button.

We can access individual children using their indexes.

Accessing Individual Children
let container = document.getElementById("container");

console.log(container.children[0]); // h2

console.log(container.children[1]); // first p

console.log(container.children[2]); // second p

console.log(container.children[3]); // button

firstElementChild and lastElementChild

These properties allow us to access the first and last child elements directly.

First and Last Child Elements
let container = document.getElementById("container");

console.log(container.firstElementChild);

console.log(container.lastElementChild);

11. Understanding childNodes

The childNodes property returns all child nodes, including element nodes, text nodes and comment nodes.

childNodes
let container = document.getElementById("container");

console.log(container.childNodes);

An important difference is that spaces and line breaks in HTML can create text nodes.

For example, the line breaks and indentation between HTML elements may appear as whitespace text nodes.

children vs childNodes
let container = document.getElementById("container");

console.log(container.children);
// Only HTML element children

console.log(container.childNodes);
// All child nodes, including whitespace text nodes

This difference is important when accessing children by their index. If we want only HTML elements, children is usually the clearer choice.

12. Accessing Sibling Elements

Siblings are nodes that share the same parent. JavaScript provides properties to move between them.

A. nextElementSibling

It returns the next sibling element.

Next Element Sibling

B. previousElementSibling

It returns the previous sibling element.

Previous Element Sibling
let second = document.getElementById("secondPara");

console.log(second.previousElementSibling);

// Output: The first paragraph element

C. nextSibling and previousSibling

These properties return the next or previous node, which may be a text node, comment node or element node.

Sibling Node Properties
let first = document.getElementById("firstPara");

console.log(first.nextSibling);

console.log(first.nextElementSibling);

Because HTML indentation often creates whitespace text nodes, nextSibling and nextElementSibling may return different results.

16 — JAVASCRIPT EVENTS

How Do Events Make Web Pages Interactive?

While learning DOM selection and navigation, I understood how JavaScript can find and modify HTML elements. But I wanted to know how a web page responds when a user interacts with it.

For example, when we click a button, type inside an input field, select an option or submit a contact form, something happens on the web page.

JavaScript uses events to detect these interactions and execute code in response.

An interactive website does not just display information. It listens, responds and communicates with its users.

1. What Is an Event in JavaScript?

An event is an action or occurrence recognised by the browser that JavaScript can respond to.

Events can happen because of user interactions or browser activities.

  • A user clicks a button.
  • A user types inside a text field.
  • A user submits a form.
  • A web page finishes loading.
  • A user changes a selected option.
  • A keyboard key is pressed or released.

JavaScript can listen for these events and execute a particular function when they occur.

2. What Is Event Handling?

Event handling means writing JavaScript code that responds to a particular event.

For example, suppose we have a button and want to display a message whenever someone clicks it.

HTML
<button id="myButton">Click Me</button>
JavaScript
let button = document.getElementById("myButton");

button.onclick = function() {

    alert("You clicked the button!");

};

Here, the onclick event handler runs the function when the user clicks the button.

This is one way of handling events. However, modern JavaScript commonly uses the addEventListener() method.

3. Understanding addEventListener()

The addEventListener() method attaches an event listener to an HTML element. It tells JavaScript which event to listen for and which function to execute when that event happens.

Its basic syntax is:

addEventListener() Syntax
element.addEventListener("eventName", function() {

    // Code to execute when the event occurs

});

Let's understand its parts:

  • element: The HTML element that will listen for the event.
  • addEventListener: The method used to register an event listener.
  • eventName: The event we want to detect, such as click or input.
  • function: The callback function that runs when the event occurs.
Button Click Event
let button = document.getElementById("myButton");

button.addEventListener("click", function() {

    console.log("Button clicked!");

});

Notice that we write "click", not "onclick", inside addEventListener().

4. Common JavaScript Events

JavaScript provides many events for handling different types of user interactions.

A. Mouse Events

Mouse events occur when users interact with elements using a mouse or another pointing device.

  • click: When an element is clicked.
  • dblclick: When an element is double-clicked.
  • mouseover: When the pointer moves onto an element or one of its descendants.
  • mouseout: When the pointer leaves an element or one of its descendants.
  • mouseenter: When the pointer enters an element.
  • mouseleave: When the pointer leaves an element.
Mouse Event Example
let heading = document.querySelector("#heading");

heading.addEventListener("mouseenter", function() {

    heading.style.color = "blue";

});

heading.addEventListener("mouseleave", function() {

    heading.style.color = "black";

});

B. Keyboard Events

Keyboard events allow JavaScript to respond when a keyboard key is pressed or released.

  • keydown: When a key is pressed.
  • keyup: When a key is released.
Keyboard Event Example
document.addEventListener("keydown", function(event) {

    console.log("Key pressed:", event.key);

});

Here, the event parameter provides information about the keyboard interaction. The key property tells us which key was pressed.

C. Form and Input Events

These events are especially useful when building registration forms, login pages, search boxes and contact forms.

  • input: When the value of an input or textarea changes through user interaction.
  • change: When a control's value is committed or changed according to that control's behaviour.
  • submit: When a form is submitted.
  • focus: When an element receives focus.
  • blur: When an element loses focus.

5. Understanding the input Event

The input event is triggered when a user changes the value of a text input or textarea.

For example, imagine we want to display whatever a visitor types inside a text field.

HTML
<input type="text" id="username" placeholder="Enter your name">

<p id="output"></p>
JavaScript
let username = document.getElementById("username");

let output = document.getElementById("output");

username.addEventListener("input", function() {

    output.textContent = username.value;

});

Every time the visitor changes the input value, JavaScript updates the paragraph.

The value property provides the current value entered in the input field.

6. Understanding the change Event

The change event is useful when we want to respond after a user changes a form control's value.

For example, when someone selects a course from a dropdown list, we can display the selected course.

HTML
<select id="course">

    <option value="">Select a course</option>

    <option value="BCA">BCA</option>

    <option value="MCA">MCA</option>

    <option value="B.Tech">B.Tech</option>

</select>

<p id="selectedCourse"></p>
JavaScript
let course = document.getElementById("course");

let selectedCourse =
    document.getElementById("selectedCourse");

course.addEventListener("change", function() {

    selectedCourse.textContent =
        "Selected Course: " + course.value;

});

The change event behaves differently depending on the form control. For a text input, it generally fires when the value is committed, often after the field loses focus. For a select element, it fires when the selection changes.

7. What Is the Event Object?

Whenever an event occurs, the browser creates an event object containing information about that event.

We can receive this object as a parameter inside the event handler function.

Event Object Example
let button = document.querySelector("#myButton");

button.addEventListener("click", function(event) {

    console.log(event);

    console.log(event.type);

    console.log(event.target);

});

Let's understand these properties:

  • event: Contains information about the event.
  • event.type: Returns the event type, such as click.
  • event.target: Refers to the element where the event originated.
  • event.currentTarget: Refers to the element whose event listener is currently running.
  • event.key: Provides the key value for keyboard events.

The event parameter can have another variable name, but developers commonly use event or e.

Using e as the Event Parameter
button.addEventListener("click", function(e) {

    console.log(e.type);

    console.log(e.target);

});

8. Understanding preventDefault()

Some HTML elements have default browser behaviour. For example, submitting a form normally causes the browser to perform a form submission.

The preventDefault() method prevents that default action when the event is cancelable.

HTML Form
<form id="contactForm">

    <input type="text" placeholder="Your name">

    <button type="submit">Send Message</button>

</form>
JavaScript
let form = document.getElementById("contactForm");

form.addEventListener("submit", function(event) {

    event.preventDefault();

    console.log("Form submission handled by JavaScript.");

});

Here, preventDefault() stops the browser's normal form submission. We can then handle the form data using JavaScript.

Remember: preventing the browser's default action does not automatically validate or save the form. We still need to write the required validation and submission logic.

9. What Is Event Bubbling?

Event bubbling is a behaviour in which an event that starts on a child element can propagate upward through its parent elements in the DOM tree.

Let's understand it with a simple example:

HTML
<div id="parent">

    Parent Element

    <button id="child">Click Me</button>

</div>
JavaScript
let parent = document.getElementById("parent");

let child = document.getElementById("child");

parent.addEventListener("click", function() {

    console.log("Parent clicked");

});

child.addEventListener("click", function() {

    console.log("Child clicked");

});

When we click the button, the output is generally:

Console Output
Child clicked

Parent clicked

The event first reaches the button and then bubbles upward to the parent div.

stopPropagation()

If we want to stop the event from propagating further, we can use event.stopPropagation().

Stopping Event Bubbling
child.addEventListener("click", function(event) {

    console.log("Child clicked");

    event.stopPropagation();

});

Now the click event will not continue bubbling to the parent element through this propagation path.

10. What Is Event Delegation?

Event delegation means placing one event listener on a common parent element instead of attaching separate listeners to every child element.

It works because events such as click can bubble from child elements to their parents.

HTML List
<ul id="menu">

    <li>Home</li>

    <li>About</li>

    <li>Contact</li>

</ul>
JavaScript Event Delegation
let menu = document.getElementById("menu");

menu.addEventListener("click", function(event) {

    if (event.target.matches("li")) {

        console.log("Selected:", event.target.textContent);

    }

});

Instead of adding a click listener to every li element, we add one listener to the parent ul.

This approach is especially useful when working with lists or elements that may be added dynamically.

11. Removing an Event Listener

Sometimes we may need to remove an event listener after it has been registered.

We can use removeEventListener(), but the callback function must be the same function reference that was originally registered.

Adding and Removing an Event Listener
let button = document.getElementById("myButton");

function showMessage() {

    console.log("Button clicked!");

}

// Add listener
button.addEventListener("click", showMessage);

// Remove listener
button.removeEventListener("click", showMessage);

Writing a new anonymous function inside removeEventListener() will not remove the original anonymous function because it is a different function reference.

Using the once Option

We can also tell JavaScript to run an event listener only once.

One-Time Event Listener
button.addEventListener("click", function() {

    console.log("This message appears only once.");

}, { once: true });

What Mistakes Did I Make as a Beginner?

Every learning journey comes with challenges. When I started learning programming, I was excited to explore different concepts, methods and techniques. I wanted to understand how everything worked and how I could use it to build something meaningful.

But gradually, I realised that learning programming was not just about covering topics. It required patience, concentration, logical thinking and regular practice.

Learning programming is not a race to finish topics. It is a process of understanding how things work.

1. My First Mistake — Trying to Learn Too Many Methods at Once

In the beginning, I thought I could learn a large number of JavaScript methods in a single day. Whenever I discovered a new method, I wanted to explore another one immediately.

I thought covering more methods meant making faster progress. But I gradually noticed that this approach disturbed my concentration.

When too many methods enter my mind at the same time, it becomes difficult to understand their individual purposes and differences.

For example, when learning array methods, I should not try to understand map(), filter(), reduce(), find() and forEach() all at once without practising them.

A Better Way to Learn Array Methods
const marks = [70, 85, 90, 65, 95];

Instead of rushing through every method, I prefer understanding one or two methods at a time, testing them with different examples and comparing their results.

This gives my mind enough space to understand what each method is designed to do.

2. My Second Mistake — Thinking That Memorising Is Learning

Another important thing I realised is that remembering the name and syntax of a method is not the same as understanding it.

For example, I can remember that map() returns a new array. But if I do not understand what happens to each element, how the callback works or what value is returned, my understanding is incomplete.

So instead of memorising methods, I try to understand:

  • What problem does this method solve?
  • What kind of input does it accept?
  • What happens internally when it executes?
  • What type of result does it return?
  • Does it modify the original value or create something new?
  • When would I use it in a real project?

These questions help me build understanding rather than simply remembering syntax.

18 — THINKING LIKE A DEVELOPER

What Does It Really Mean to Think Like a Developer?

When I first started learning programming, I thought becoming a developer mainly meant learning programming languages, remembering their syntax and writing code.

But as I explored HTML, CSS and JavaScript, I gradually understood that programming is much more than writing instructions. It is about understanding problems, thinking logically, planning solutions and converting those solutions into working code.

A developer does not simply ask, "Which code should I write?" A developer first asks, "What am I trying to achieve, and how can I solve this problem?"

Writing code is an activity. Solving problems through code is a developer's way of thinking.

1. First, Understand the Problem

Before writing code, I need to understand the actual problem. If I start coding without knowing what result I want, I may write instructions that do not solve the right problem.

Imagine I am creating a small shopping application. A user adds products to a cart, and the application needs to calculate the total price.

Before writing JavaScript, I identify:

  • Input: Product prices and quantities.
  • Process: Multiply each price by its quantity and calculate the total.
  • Output: The final shopping bill.

This simple process helps me understand what the program needs to do before I choose any JavaScript method or function.

2. Break a Big Problem into Smaller Steps

Sometimes a project looks complicated because it contains many different tasks. Instead of trying to solve everything together, I can divide the problem into smaller parts.

For example, a shopping cart may require:

  • Storing product information.
  • Adding products to the cart.
  • Updating product quantities.
  • Calculating the total amount.
  • Displaying the final bill.

Each task can be developed and tested separately. After that, I can connect the different parts.

3. Choose the Right Programming Concept

Once I understand the problem, I need to decide which JavaScript concepts can help me solve it. Not every problem requires the same method.

For example:

  • Variables store information.
  • Conditions make decisions.
  • Loops repeat instructions.
  • Functions organise reusable logic.
  • Arrays organise collections of data.
  • Array methods help process collections.
  • DOM methods help interact with HTML elements.
  • Events respond to user actions.

Understanding the purpose of each concept helps me select an appropriate solution instead of using methods randomly.

4. Think Before Writing the Code

I believe one of the most important habits of a developer is planning before coding.

I try to visualise the complete process in my mind. I think about the input, expected output, required conditions, brackets, parameters and arguments.

For example, suppose I want to calculate the total price of products in a shopping cart.

My Logic Before Coding
1. I have a list of products.

2. Every product has a price and quantity.

3. Multiply price by quantity.

4. Add all product totals.

5. Return the final amount.

Now I can convert this logic into JavaScript.

Implementing the Shopping Cart Logic
const cart = [
    { name: "Notebook", price: 50, quantity: 2 },
    { name: "Pen", price: 10, quantity: 5 },
    { name: "Bag", price: 500, quantity: 1 }
];

function calculateCartTotal(products) {

    const total = products.reduce((sum, product) => {
        return sum + (product.price * product.quantity);
    }, 0);

    return total;
}

const finalBill = calculateCartTotal(cart);

console.log(finalBill);

// Output: 650

Here, I use an array of objects to store product information, a function to organise the calculation and reduce() to calculate the final amount.

Each concept has a specific responsibility. This is how different JavaScript concepts can work together to solve one practical problem.

5. Understand How Data Moves Through a Program

A developer needs to understand how information enters a program, how it is processed and what result comes out.

In our shopping cart example:

  • The cart array contains the input data.
  • The calculateCartTotal() function processes that data.
  • The reduce() method adds the individual product totals.
  • The return statement sends the final value back.
  • The console displays the result.

Understanding this flow helps me follow the execution of a program instead of looking at code as unrelated lines.

Testing different situations helps me discover problems that may not appear in the first example.
