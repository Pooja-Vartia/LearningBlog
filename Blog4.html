Every new technology opens another door in my web development journey. After learning how to structure, style, animate and make webpages responsive, I am now exploring how websites process information behind the scenes — with PHP.

01. Where My PHP Journey Began

After exploring HTML, CSS, JavaScript and Bootstrap, I started understanding that creating a website is not only about what visitors can see on their screens. There is another important part that works behind the scenes.

Until now, I had mainly worked with the frontend — creating webpage structures, styling elements, adding interactions and making layouts responsive. But I wanted to understand something more: How does a website receive information from users? How does it process form data? And how can information be stored and retrieved from a database?

This is where my journey with PHP began.

PHP introduced me to server-side programming. I started learning how a website can communicate with a server, process user requests, work with databases and generate dynamic webpage content.

My learning thought: A frontend gives a website its visible experience, but backend programming helps it perform meaningful tasks. I was now stepping into a new side of web development.

02. The History and Origin of PHP

Before writing my first PHP program, I wanted to understand where PHP came from and why it was created.

PHP was originally created by Rasmus Lerdorf in 1994. Initially, he wrote a collection of CGI programs in the C programming language to maintain his personal homepage.

Later, he wanted to extend those programs so that his homepage could interact with web forms and communicate with databases. This requirement led to the development of a more useful set of tools.

Personal Home Page Tools

The original tools were known as Personal Home Page Tools. They helped manage a personal website and handle information submitted through web forms.

PHP/FI — Forms Interpreter

The project later developed into PHP/FI, where FI stood for Forms Interpreter. It provided more capabilities for processing form data and interacting with databases.

How did PHP get its current name?

As PHP continued to develop, it became a more powerful server-side scripting language. PHP 3 introduced the recursive acronym: PHP: Hypertext Preprocessor.

My historical understanding

  • 1994 — Rasmus Lerdorf created the original PHP tools.
  • Personal Home Page — The original purpose was managing a personal homepage.
  • PHP/FI — The tools evolved to handle forms and database communication.
  • PHP 3 — The name PHP: Hypertext Preprocessor became established.

This history helped me understand that PHP was not initially designed as the large web development language we use today. It evolved to solve practical problems related to websites.

03. Understanding PHP as a Scripting Language

While learning PHP, I came across the term scripting language. Before understanding PHP, I first wanted to understand what a script actually means.

What is a script?

A script is a set of instructions written to perform a particular task. These instructions tell a computer what action to perform and in which order.

For example, when a visitor submits a contact form, a PHP script can receive the submitted information, validate it and save it into a database.

What is a scripting language?

A scripting language is a programming language commonly used to write instructions that are executed by a runtime environment or interpreter.

PHP is a server-side scripting language. This means its code normally runs on a web server rather than directly inside the visitor's browser.

How does PHP work?

  1. A visitor requests a PHP webpage through a browser.
  2. The web server receives the request.
  3. The PHP interpreter executes the PHP code.
  4. The server prepares the resulting output, commonly HTML.
  5. The browser receives and displays that output.

Understanding the difference

JavaScript in the browser:

It can respond to user actions, update webpage content and create interactive experiences on the client side.

PHP on the server:

It can process submitted information, communicate with databases, manage sessions and generate webpage output.

What I understood: PHP works behind the scenes. Visitors generally receive the output generated by PHP, not the original PHP source code.

04. What Does PHP Stand For?

One of the first things I learned about PHP was its full form.

PHP: Hypertext Preprocessor

PHP is a recursive acronym. It means that the abbreviation PHP appears again inside its own full form.

PHP is mainly used for server-side web development. It can generate dynamic HTML pages, process form submissions, communicate with databases and manage server-side sessions.

Why is it called a server-side language?

Because PHP code is generally executed on the server. After execution, the server sends the generated response to the visitor's browser.

For example, a website can display a different welcome message depending on the currently logged-in user. PHP can help generate that personalized output.

Where can PHP be used?

  • Login and registration systems
  • Contact forms
  • Database operations
  • Dynamic webpages
  • Session management
  • Content management systems

05. Setting Up a Local Server with XAMPP

After understanding what PHP is, my next step was to learn where and how PHP programs are executed.

Unlike a simple HTML file that can be opened directly in a browser, PHP needs a PHP-enabled server environment to execute its code.

What is a local server?

A local server is a server environment running on our own computer. It allows us to develop and test websites without publishing them on the internet.

During my learning process, I used XAMPP to create a local development environment.

What is XAMPP?

XAMPP is a free and open-source package that provides the main tools required to run and test dynamic websites locally.

Its name represents the main technologies included in the package.

Full form of XAMPP

  • X — Cross-platform
  • A — Apache
  • M — MySQL (commonly MariaDB in current XAMPP distributions)
  • P — PHP
  • P — Perl

How did I use XAMPP?

  1. First, I installed XAMPP on my computer.
  2. I opened the XAMPP Control Panel.
  3. I started the Apache server.
  4. I started MySQL when database functionality was required.
  5. I placed my PHP project inside the htdocs folder.
  6. I opened the project through localhost in my browser.

Understanding localhost

Localhost refers to the computer on which the server is running. It is commonly associated with the IP address 127.0.0.1.

For example, if my project folder is named MyPHPProject, I can access it using: 

http://localhost/MyPHPProject/
My learning experience: XAMPP helped me understand how a local computer can behave like a web server and execute PHP programs before a website is deployed online.

06. Understanding the Components of XAMPP

After installing XAMPP, I wanted to understand what each component actually does. Knowing their individual responsibilities made the complete server environment easier to understand.

1. Apache — The Web Server

Apache is a web server software. It receives requests from browsers and helps deliver the requested webpage or other resources.

When I access a PHP project through localhost, Apache receives the browser request and works with PHP to process the PHP page.

2. MySQL / MariaDB — The Database Server

A database is used to store and organize information. MySQL is a relational database management system. Current XAMPP distributions commonly include MariaDB, which is compatible with many MySQL workflows.

For example, a registration form can collect a user's name, email and password. PHP can process that information and store it in a database.

3. PHP — The Server-Side Language

PHP is the scripting language used to write the server-side logic of a website.

It can receive form data, validate information, perform calculations, communicate with databases and generate dynamic webpage content.

4. Perl — Another Programming Language

Perl is a programming language that can also be included in the XAMPP package. It is useful for scripting and text-processing tasks.

5. Cross-platform

The letter X represents cross-platform. It indicates that XAMPP is available for multiple operating systems, including Windows, Linux and macOS.

Quick comparison of XAMPP components

  • Apache: Handles web requests.
  • MySQL / MariaDB: Stores and manages data.
  • PHP: Executes server-side application logic.
  • Perl: Provides another scripting language.
  • Cross-platform: Supports different operating systems.
What I understood: These components work together to provide a local environment where I can develop, test and run dynamic PHP websites.

07. Understanding the Structure of a PHP Program

After setting up my local server using XAMPP, I was ready to write my first PHP program. Before writing different instructions, I first needed to understand how a PHP program is structured.

PHP code is generally written inside a PHP file with the .php extension. A PHP file can contain HTML, CSS, JavaScript and PHP code together.

My First PHP Program

<?php

echo "Hello World!";

?>

Understanding the code step by step

  • <?php — It tells the PHP interpreter that PHP code begins here.
  • echo — It is used to display output.
  • "Hello World!" — This is the string value that we want to display.
  • ; — It marks the end of the PHP statement.
  • ?> — It marks the end of a PHP code block when a closing tag is needed.

Where do I save this program?

I save my file with a .php extension, for example: 

firstprogram.php

Then I place it inside the XAMPP htdocs folder and run it through localhost: 

http://localhost/firstprogram.php
What I understood: A PHP program is not simply opened like an ordinary static HTML file. It needs a PHP-enabled server environment to execute its server-side instructions.

08. Why Do We Use the PHP Tags?

While writing PHP code, I noticed that it starts with a special opening tag and sometimes ends with a closing tag. I wanted to understand why these tags are necessary.

Opening PHP Tag

The opening tag <?php tells the PHP interpreter where PHP code starts.

Closing PHP Tag

The closing tag ?> tells the PHP interpreter where the PHP code block ends. After it, the file can contain ordinary HTML.

Combining PHP and HTML

One useful feature of PHP is that we can write PHP and HTML in the same file. This helps us generate dynamic webpage content. 

<!DOCTYPE html>
<html lang="en">
<head>
    <title>My PHP Page</title>
</head>

<body>

    <h1>Welcome to My Website</h1>

    <?php
        echo "This message is generated using PHP.";
    ?>

</body>
</html>

Can we omit the closing PHP tag?

Yes. When a PHP file contains only PHP code, the closing PHP tag is commonly omitted. This helps avoid accidental whitespace or unwanted output after the PHP code.

What I learned: PHP tags separate server-side PHP instructions from ordinary HTML content. They allow both technologies to work together in one webpage.

09. Displaying Output with echo

Once I understood the PHP structure, my next step was learning how to display information on a webpage. In PHP, one of the most commonly used language constructs for displaying output is echo.

What is echo?

The echo construct is used to send one or more expressions to the output. That output can be displayed by the browser when the server returns the generated webpage.

Example 1: Displaying text

<?php

echo "Hello, Pooja!";

?>

Example 2: Displaying HTML using echo

<?php

echo "<h2>Learning PHP</h2>";
echo "<p>This is my PHP learning journey.</p>";

?>

Example 3: Displaying multiple values

<?php

echo "My name is ", "Pooja", " Vartia.";

?>

Important points about echo

  • echo is a PHP language construct.
  • It can display strings, variables and expressions.
  • It can output multiple comma-separated arguments.
  • It does not return a value like an ordinary function.
  • A semicolon normally ends the PHP statement.
What I understood: echo is useful whenever I want PHP to generate visible webpage output, such as headings, messages or dynamic values.

10. Variables and Loosely Typed Behaviour in PHP

After learning how to display output, I moved towards variables. Variables allow us to store information and use it whenever required.

What is a variable?

A variable is a named storage location used to hold a value during program execution. In PHP, every variable begins with a dollar sign ($).

Creating variables in PHP

<?php

$name = "Pooja";
$age = 22;
$percentage = 85.5;
$isLearning = true;

echo $name;
echo $age;
echo $percentage;

?>

Understanding the variable values

  • $name stores a string value.
  • $age stores an integer.
  • $percentage stores a floating-point number.
  • $isLearning stores a Boolean value.

Why is PHP called a loosely typed language?

PHP is dynamically typed. It means we generally do not need to declare the data type of a variable before assigning a value to it. PHP determines the variable's type from the value assigned. 

<?php

$value = 100;

echo $value;

$value = "Hello PHP";

echo $value;

?>

In this example, the same variable first holds an integer and later holds a string. PHP allows this because variable types are determined dynamically.

Common data types in PHP

  • Integer: Whole numbers, such as 25.
  • Float: Decimal numbers, such as 25.5.
  • String: Text values, such as "Hello".
  • Boolean: true or false.
  • Array: A collection of values.
  • Object: An instance of a class.
  • NULL: Represents a variable with no value.

Checking a variable's type

PHP provides the gettype() function to identify the type of a variable. 

<?php

$age = 22;

echo gettype($age);

?>

Rules for naming PHP variables

  • A variable must begin with the $ symbol.
  • The first character after $ must be a letter or underscore.
  • A variable name cannot start with a number.
  • Variable names are case-sensitive.
  • Spaces are not allowed in variable names.
<?php

$studentName = "Pooja";
$_total = 500;

// Invalid examples:
// $2name = "Pooja";
// $student name = "Pooja";

?>
What I understood: Variables help PHP remember information during program execution. Its dynamic typing makes assigning different kinds of values easier.

11. Expressions and Operators in PHP

After understanding variables, I learned how PHP performs calculations and evaluates values. This introduced me to expressions and operators.

What is an expression?

An expression is a combination of values, variables, operators and sometimes function calls that PHP evaluates to produce a result. 

<?php

$a = 10;
$b = 5;

$result = $a + $b;

echo $result;

?>

Here, $a + $b is an expression. PHP evaluates it and produces the result 15.

What is an operator?

An operator is a symbol or keyword that performs an operation on one or more values.

1. Arithmetic Operators

These operators perform mathematical calculations. 

<?php

$a = 10;
$b = 3;

echo $a + $b;  // Addition
echo $a - $b;  // Subtraction
echo $a * $b;  // Multiplication
echo $a / $b;  // Division
echo $a % $b;  // Modulus
echo $a ** $b; // Exponentiation

?>

2. Assignment Operators

Assignment operators assign values to variables or update their existing values. 

<?php

$x = 10;

$x += 5;  // Same as $x = $x + 5
$x -= 2;  // Same as $x = $x - 2
$x *= 2;  // Same as $x = $x * 2
$x /= 2;  // Same as $x = $x / 2

echo $x;

?>

3. Comparison Operators

Comparison operators compare two values and return a Boolean result: true or false. 

<?php

$a = 10;
$b = 20;

var_dump($a == $b);
var_dump($a === $b);
var_dump($a != $b);
var_dump($a < $b);
var_dump($a > $b);
var_dump($a <= $b);
var_dump($a >= $b);

?>

An important difference is that == compares values after type conversion where applicable, whereas === checks both value and type.

4. Logical Operators

Logical operators combine or reverse conditions. 

<?php

$age = 22;
$hasID = true;

var_dump($age >= 18 && $hasID);
var_dump($age >= 18 || $hasID);
var_dump(!$hasID);

?>

5. Increment and Decrement Operators

These operators increase or decrease a variable by one. 

<?php

$count = 5;

$count++;
echo $count;

$count--;
echo $count;

?>
What I understood: Expressions combine values and operations, while operators tell PHP what action to perform — such as adding, comparing or assigning values.

12. Conditional Statements — Teaching PHP to Make Decisions

After learning operators, I started understanding how a PHP program can make decisions. A program does not always need to execute every instruction in the same way. Sometimes it must choose an action depending on a condition.

What is a conditional statement?

A conditional statement allows a program to execute different blocks of code depending on whether a condition is true or false.

1. The if Statement

The if statement executes its code block only when the given condition is true. 

<?php

$age = 20;

if ($age >= 18) {
    echo "You are eligible to vote.";
}

?>

2. The if-else Statement

The if-else statement provides two possible paths. If the condition is true, the if block executes. Otherwise, the else block executes. 

<?php

$number = 7;

if ($number % 2 == 0) {

    echo "Even Number";

} else {

    echo "Odd Number";

}

?>

3. The if-elseif-else Statement

When we need to check multiple conditions, we can use elseif. 

<?php

$marks = 85;

if ($marks >= 90) {

    echo "Grade A+";

} elseif ($marks >= 75) {

    echo "Grade A";

} elseif ($marks >= 60) {

    echo "Grade B";

} else {

    echo "Needs Improvement";

}

?>

4. The switch Statement

The switch statement is useful when we want to compare one expression against several possible values. 

<?php

$day = 2;

switch ($day) {

    case 1:
        echo "Monday";
        break;

    case 2:
        echo "Tuesday";
        break;

    case 3:
        echo "Wednesday";
        break;

    default:
        echo "Other day";

}

?>

The break statement stops execution from continuing into the following cases.

5. The Ternary Operator

The ternary operator is a short way of writing a simple if-else expression. 

<?php

$age = 20;

$message = ($age >= 18)
    ? "Adult"
    : "Minor";

echo $message;

?>

Understanding conditional execution

Suppose I want to check whether a student has passed an examination.

  • If marks are 40 or above, display Pass.
  • Otherwise, display Fail.

PHP evaluates the condition and executes the appropriate block.

What I understood: Conditional statements give decision-making ability to a program. They help PHP respond differently according to the values and conditions provided.

13. Prime Number or Not — A Practical Condition Example

After learning conditional statements, I wanted to understand how conditions could solve an actual programming problem. One interesting example was checking whether a given number is prime or not.

What is a prime number?

A prime number is a natural number greater than 1 that has exactly two distinct positive factors: 1 and the number itself.

For example, 2, 3, 5, 7, 11 and 13 are prime numbers. However, 4, 6, 8 and 9 are not prime numbers because they have additional factors.

How can I check a prime number?

To check whether a number is prime, I need to determine whether any number other than 1 and itself can divide it completely.

The modulus operator (%) helps us perform this check because it returns the remainder after division.

PHP program to check a prime number

<?php

$number = 17;
$isPrime = true;

if ($number <= 1) {

    $isPrime = false;

} else {

    for ($i = 2; $i <= sqrt($number); $i++) {

        if ($number % $i == 0) {

            $isPrime = false;
            break;

        }

    }

}

if ($isPrime) {

    echo "$number is a Prime Number.";

} else {

    echo "$number is not a Prime Number.";

}

?>

Understanding the program step by step

  1. First, I store the number 17 in the $number variable.
  2. I create a Boolean variable $isPrime and initially assign true to it.
  3. If the number is less than or equal to 1, it cannot be prime.
  4. Otherwise, the for loop checks possible divisors starting from 2.
  5. If the modulus result is 0, the number is divisible by that divisor.
  6. The program changes $isPrime to false and uses break to stop the loop.
  7. Finally, the if-else statement displays the result.

We only need to check divisors up to the square root of the number. If a number has a divisor greater than its square root, it must also have a corresponding divisor smaller than its square root.

What I understood: This example helped me connect variables, Boolean values, modulus, loops and conditional statements in one practical PHP program.

14. String Concatenation in PHP

While working with variables and output, I learned that sometimes we need to combine multiple strings or variable values into one complete sentence.

This process is called string concatenation.

What is the concatenation operator?

PHP uses the dot (.) operator to join strings together.

Example 1: Joining two strings

<?php

$firstName = "Pooja";
$lastName = "Vartia";

$fullName = $firstName . " " . $lastName;

echo $fullName;

?>

Example 2: Joining text with variables

<?php

$name = "Pooja";
$course = "BCA";

echo "My name is " . $name . " and I completed " . $course . ".";

?>

Example 3: Concatenation assignment operator

PHP also provides the .= operator. It appends additional text to an existing string variable. 

<?php

$message = "Welcome";

$message .= " to PHP";
$message .= " Learning!";

echo $message;

?>

Difference between arithmetic and concatenation

<?php

$a = 10;
$b = 20;

echo $a + $b;       // Addition: 30

echo "10" . "20";   // Concatenation: 1020

?>
What I understood: The dot operator joins strings, whereas the plus operator performs addition. Understanding this difference is important when working with text and numeric values.

15. Useful PHP String Functions

After learning string concatenation, I explored some built-in PHP functions that make working with text easier.

A string is a sequence of characters. PHP provides several functions to calculate its length, change its case, search within it and replace particular text.

1. strlen() — Finding String Length

The strlen() function returns the number of bytes in a string. For ordinary ASCII text, this usually matches the character count. 

<?php

$name = "Pooja";

echo strlen($name);

// Output: 5

?>

2. str_word_count() — Counting Words

This function counts the words recognized in a string. 

<?php

$sentence = "I am learning PHP programming";

echo str_word_count($sentence);

// Output: 5

?>

3. strtoupper() — Converting to Uppercase

<?php

$text = "hello php";

echo strtoupper($text);

// Output: HELLO PHP

?>

4. strtolower() — Converting to Lowercase

<?php

$text = "HELLO PHP";

echo strtolower($text);

// Output: hello php

?>

5. ucfirst() — Capitalizing the First Character

<?php

$text = "learning php";

echo ucfirst($text);

// Output: Learning php

?>

6. ucwords() — Capitalizing Each Word

<?php

$text = "learning php programming";

echo ucwords($text);

// Output: Learning Php Programming

?>

7. str_replace() — Replacing Text

This function replaces specified text with another value. 

<?php

$text = "I like JavaScript";

echo str_replace("JavaScript", "PHP", $text);

// Output: I like PHP

?>

8. trim() — Removing Extra Whitespace

The trim() function removes whitespace and certain other characters from the beginning and end of a string. 

<?php

$name = "   Pooja   ";

echo trim($name);

// Output: Pooja

?>

9. strpos() — Finding Text Position

The strpos() function finds the position of the first occurrence of a substring. PHP string positions start from zero. 

<?php

$text = "Learning PHP";

echo strpos($text, "PHP");

// Output: 9

?>

Some useful string functions at a glance

  • strlen(): Finds string length in bytes.
  • str_word_count(): Counts recognized words.
  • strtoupper(): Converts text to uppercase.
  • strtolower(): Converts text to lowercase.
  • ucfirst(): Capitalizes the first character.
  • ucwords(): Capitalizes the first character of each word.
  • str_replace(): Replaces specified text.
  • trim(): Removes whitespace from the ends.
  • strpos(): Finds the position of a substring.
What I understood: Built-in string functions save time because I do not have to write every text-processing operation manually.

16. Looping Statements in PHP

While writing programs, I noticed that sometimes we need to perform the same task repeatedly. Writing the same instruction again and again would make the program longer and harder to manage.

This is where loops become useful.

What is a loop?

A loop is a programming structure that executes a block of code repeatedly as long as its specified condition allows it to continue.

1. The while Loop

The while loop checks its condition before executing the loop body. If the condition is true, the statements inside the loop execute. 

<?php

$i = 1;

while ($i <= 5) {

    echo $i . "<br>";

    $i++;

}

?>

The loop starts at 1 and continues until the value becomes greater than 5.

2. The do-while Loop

The do-while loop executes its body first and checks the condition afterwards. Therefore, its statements execute at least once. 

<?php

$i = 1;

do {

    echo $i . "<br>";

    $i++;

} while ($i <= 5);

?>

3. The for Loop

A for loop is useful when we know how many times we want to repeat a task. Its structure contains initialization, condition and update. 

<?php

for ($i = 1; $i <= 5; $i++) {

    echo $i . "<br>";

}

?>

Understanding the three parts of a for loop

  • Initialization: $i = 1 sets the starting value.
  • Condition: $i <= 5 decides whether the loop continues.
  • Update: $i++ increases the counter after each iteration.

4. The foreach Loop

The foreach loop is specially useful for traversing arrays. We will explore it in more detail when learning PHP arrays. 

<?php

$colors = ["Red", "Green", "Blue"];

foreach ($colors as $color) {

    echo $color . "<br>";

}

?>

Understanding break and continue

PHP also provides two useful statements that control loop execution.

  • break: Immediately terminates the loop.
  • continue: Skips the remaining statements in the current iteration and moves to the next one. 
<?php

for ($i = 1; $i <= 5; $i++) {

    if ($i == 3) {
        continue;
    }

    echo $i . "<br>";

}

?>

In this example, the number 3 is skipped because continue moves execution to the next iteration.

What I understood: Loops reduce repeated code and make programs more efficient. Different loops are useful for different situations depending on how and when their conditions are checked.

17. PHP Functions — Reusing Code

After learning loops, I moved towards another important programming concept: functions. While writing programs, I realized that some tasks may need to be performed more than once.

Instead of writing the same code repeatedly, we can place those instructions inside a function and call it whenever required.

What is a function?

A function is a reusable block of code designed to perform a particular task.

Creating a user-defined function

PHP allows us to create our own functions using the function keyword. 

<?php

function greet() {

    echo "Hello! Welcome to PHP.";

}

greet();

?>

Understanding the function structure

  • function: Keyword used to declare a function.
  • greet: Name of the function.
  • (): Parentheses that contain parameters when needed.
  • { }: Curly braces that contain the function body.
  • greet(): Calling the function so its code executes.

Example: Calling a function multiple times

<?php

function welcomeMessage() {

    echo "Welcome to my learning journey!<br>";

}

welcomeMessage();
welcomeMessage();
welcomeMessage();

?>

Instead of writing the same message three times, I created one function and called it three times.

Built-in and user-defined functions

During my learning, I also understood that PHP functions can be grouped into two broad categories.

  • Built-in functions: Functions already provided by PHP, such as strlen(), date() and rand().
  • User-defined functions: Functions created by programmers according to their requirements.
What I understood: Functions make code reusable and organized. They help divide a large program into smaller tasks that are easier to understand, test and maintain.

18. Function Arguments and Default Values

In the previous chapter, I learned how to create and call a function. But I also wanted to understand how a function can work with different values.

For example, if I create a function to welcome someone, I should be able to provide a different person's name whenever I call that function. This is where function parameters and arguments become useful.

What are parameters?

Parameters are variables written inside the parentheses of a function declaration. They receive values when the function is called.

What are arguments?

Arguments are the actual values passed to a function when we call it.

Example 1: Function with one parameter

<?php

function greet($name) {

    echo "Hello " . $name . "!<br>";

}

greet("Pooja");
greet("Riya");
greet("Aman");

?>

Here, $name is the parameter, while Pooja, Riya and Aman are arguments. The same function can display different names depending on the argument provided.

Example 2: Function with multiple parameters

<?php

function addNumbers($a, $b) {

    $sum = $a + $b;

    echo "Sum = " . $sum;

}

addNumbers(10, 20);

?>

In this example, the function accepts two parameters and performs addition using their values.

What is a default parameter value?

Sometimes, we may want a function to use a predefined value when an argument is not supplied. PHP allows us to assign default values to parameters. 

<?php

function welcome($name = "Guest") {

    echo "Welcome " . $name . "!<br>";

}

welcome("Pooja");

welcome();

?>

In the first function call, Pooja is passed as an argument. In the second call, no argument is provided, so PHP uses Guest as the default value.

Example 3: Default values with multiple parameters

<?php

function calculateTotal($price, $quantity = 1) {

    $total = $price * $quantity;

    echo "Total = " . $total . "<br>";

}

calculateTotal(500, 3);

calculateTotal(500);

?>

The first call calculates 500 multiplied by 3. The second call uses the default quantity of 1.

What I understood: Parameters make functions flexible because we can provide different inputs without rewriting the function. Default values make arguments optional when appropriate.

19. Pass by Value and Pass by Reference

After understanding function arguments, I explored how values are passed into functions and whether changes made inside a function affect the original variable.

PHP commonly passes arguments by value. It also allows us to pass a variable by reference using the ampersand (&) symbol.

1. Pass by Value

In pass by value, the function receives a copy of the argument's value. Changes made to the function parameter do not change the original variable. 

<?php

function changeValue($number) {

    $number = 100;

    echo "Inside function: " . $number . "<br>";

}

$value = 50;

changeValue($value);

echo "Outside function: " . $value;

?>

Understanding the output

Inside the function, the parameter becomes 100. However, the original $value variable remains 50 because the function received its value rather than a reference to the original variable.

2. Pass by Reference

In pass by reference, the function receives a reference to the original variable. Therefore, changes made through the parameter affect the original variable. 

<?php

function changeValue(&$number) {

    $number = 100;

}

$value = 50;

changeValue($value);

echo $value;

// Output: 100

?>

Understanding the ampersand (&)

The ampersand is written before the parameter name in the function declaration to indicate that the argument should be passed by reference.

Difference between both approaches

  • Pass by Value: The original variable is not changed by modifying the function parameter.
  • Pass by Reference: Changes made through the function parameter can affect the original variable.
What I understood: Pass by value is useful when I want a function to work with a value without changing the original variable. Pass by reference is useful when I intentionally want the function to modify the original variable.

20. Returning Values and the return Keyword

While learning functions, I noticed that sometimes a function should not directly display a result. Instead, it should calculate something and send that result back to the place where the function was called.

PHP provides the return keyword for this purpose.

What is the return keyword?

The return keyword ends the execution of a function and optionally sends a value back to the calling code.

Example 1: Returning a calculated value

<?php

function addNumbers($a, $b) {

    $sum = $a + $b;

    return $sum;

}

$result = addNumbers(10, 20);

echo $result;

?>

Understanding the program

  1. The addNumbers() function accepts two arguments.
  2. It calculates their sum.
  3. The return keyword sends the result back to the calling code.
  4. The returned value is stored in the $result variable.
  5. Finally, echo displays the result.

Example 2: Using a returned value in another expression

<?php

function square($number) {

    return $number * $number;

}

echo square(5);

$total = square(4) + square(3);

echo "<br>Total = " . $total;

?>

Here, the returned values can be used directly in another expression.

Example 3: return stops function execution

<?php

function checkNumber() {

    return "Function completed.";

    echo "This statement will not execute.";

}

echo checkNumber();

?>

Once PHP executes return, the function ends. Any statements written after that return statement in the same execution path are not executed.

Difference between echo and return

  • echo: Sends output to the webpage response.
  • return: Sends a value back to the calling code.
What I understood: echo is used to display information, whereas return is used to send a result back from a function. A returned value can be stored, reused or passed into another calculation.

21. Understanding Arrays in PHP

After learning variables and functions, I moved towards another useful concept: arrays.

Until now, I had stored individual values in separate variables. But what if I wanted to store a list of student names, colors, subjects or marks?

Creating a separate variable for every value would make the program difficult to manage. Arrays provide a better way to organize multiple values inside a single variable.

What is an array?

An array is a data structure that stores multiple values in one variable. PHP arrays can use integer or string keys to access their elements.

Creating an array in PHP

PHP provides the array() construct and the short array syntax [] to create arrays. 

<?php

$colors = array("Red", "Green", "Blue");

$subjects = ["HTML", "CSS", "PHP"];

?>

Types of PHP arrays

For learning purposes, PHP arrays are commonly discussed in three forms:

  • Indexed Array: Uses numeric keys to access values.
  • Associative Array: Uses named string keys to access values.
  • Multidimensional Array: Contains one or more arrays inside another array.

Understanding arrays with a simple example

Suppose I want to store the names of three programming languages: 

<?php

$languages = ["HTML", "CSS", "PHP"];

?>

Instead of creating three separate variables, I can keep all three values together inside one array.

What I understood: Arrays help organize related information and make it easier to work with lists of values in a PHP program.

22. Indexed Arrays and print_r()

After understanding the meaning of arrays, I started exploring their different types. The first type I learned was the indexed array.

What is an indexed array?

An indexed array is an array in which elements are accessed using numeric keys. In a newly created indexed array, the first key normally starts from 0.

Example 1: Creating an indexed array

<?php

$fruits = ["Apple", "Mango", "Orange"];

echo $fruits[0];
echo $fruits[1];
echo $fruits[2];

?>

Understanding array indexes

  • Index 0 contains Apple.
  • Index 1 contains Mango.
  • Index 2 contains Orange.

Example 2: Adding values using indexes

<?php

$subjects = [];

$subjects[0] = "HTML";
$subjects[1] = "CSS";
$subjects[2] = "PHP";

echo $subjects[2];

?>

Example 3: Displaying an entire array using print_r()

When working with arrays, displaying only one element at a time is not always useful. Sometimes I want to inspect the complete array and understand how its keys and values are organized.

PHP provides the print_r() function for displaying human-readable information about a variable, including arrays. 

<?php

$colors = ["Red", "Green", "Blue"];

echo "<pre>";

print_r($colors);

echo "</pre>";

?>

Why do we use the pre tag?

The HTML pre element displays preformatted text. It preserves spaces and line breaks, which makes the output of print_r() easier to read in a browser.

Understanding the output

Array
(
    [0] => Red
    [1] => Green
    [2] => Blue
)

This output shows the array name, its numeric indexes and their corresponding values.

Another useful function: count()

The count() function returns the number of elements in an array. 

<?php

$fruits = ["Apple", "Mango", "Orange"];

echo count($fruits);

// Output: 3

?>
What I understood: Indexed arrays organize values using numeric keys. print_r() helps inspect the complete array, while pre makes its browser output easier to read.

23. Associative and Multidimensional Arrays

In the previous section, I learned about indexed arrays, where PHP automatically assigns numeric indexes to array elements. But while working with real information, I sometimes need to remember what each value represents instead of remembering its numeric position.

This is where I discovered associative arrays. Instead of using numbers as keys, associative arrays allow us to assign meaningful names to values.

Understanding Associative Arrays

An associative array stores information in key-value pairs. Each value is connected to a named key, which makes the data easier to understand and access. 

<?php

$student = [
    "name" => "Pooja",
    "course" => "BCA",
    "marks" => 85
];

echo $student["name"];
echo $student["course"];
echo $student["marks"];

?>

Here, name, course, and marks are the keys, while Pooja, BCA, and 85 are their corresponding values.

I can access any value directly by using its key, such as $student["name"]. This is more meaningful than remembering whether a student's name is stored at index 0 or 1.

Displaying an Associative Array

<?php

$student = [
    "name" => "Pooja",
    "course" => "BCA",
    "marks" => 85
];

echo "<pre>";
print_r($student);
echo "</pre>";

?>

The print_r() function helps me inspect the complete array, while the HTML <pre> tag preserves spacing and line breaks so that the output is easier to read.

Understanding Multidimensional Arrays

After learning associative arrays, I moved towards another useful concept: multidimensional arrays.

A multidimensional array is an array that contains one or more arrays inside it. It helps us organize related information in groups, such as records of multiple students. 

<?php

$students = [
    [
        "name" => "Pooja",
        "course" => "BCA",
        "marks" => 85
    ],

    [
        "name" => "Rahul",
        "course" => "BCA",
        "marks" => 90
    ],

    [
        "name" => "Simran",
        "course" => "BCA",
        "marks" => 88
    ]
];

echo $students[0]["name"];
echo $students[1]["marks"];

?>

In this example, the main array contains three smaller associative arrays. Each inner array represents one student's record.

The expression $students[0]["name"] first accesses the first student's array using index 0 and then retrieves the value associated with the key name.

What I understood:

Indexed arrays help me store values using numeric positions, associative arrays help me store values with meaningful keys, and multidimensional arrays help me organize collections of related records.

24. Traversing Arrays with the foreach Loop

While working with arrays, I realized that accessing every value individually can become difficult when an array contains many elements.

PHP provides a special loop called foreach, which allows us to visit each element of an array one by one. It is especially useful when we do not need to manage indexes manually.

Using foreach with an Indexed Array

<?php

$subjects = ["HTML", "CSS", "JavaScript", "PHP"];

foreach ($subjects as $subject) {

    echo $subject . "<br>";

}

?>

Here, $subjects is the original array and $subject is a temporary variable that receives each value during every iteration.

The loop continues until all elements have been visited. I do not have to write separate statements for every subject.

Using foreach with an Associative Array

When I want to access both the key and its corresponding value, I can use the key => value structure. 

<?php

$student = [
    "name" => "Pooja",
    "course" => "BCA",
    "marks" => 85
];

foreach ($student as $key => $value) {

    echo $key . " : " . $value . "<br>";

}

?>

In this example, $key receives the key name and $value receives the corresponding value.

Displaying Array Values in an HTML List

Since PHP can work together with HTML, I can also use a foreach loop to generate HTML elements dynamically. 

<?php

$skills = ["HTML", "CSS", "Bootstrap", "JavaScript", "PHP"];

echo "<ul>";

foreach ($skills as $skill) {

    echo "<li>" . htmlspecialchars($skill) . "</li>";

}

echo "</ul>";

?>

Instead of manually writing five list items in HTML, PHP generates them by reading the values from the array. This becomes very useful when information comes from a database.

My learning observation:

The foreach loop made array handling easier because I could focus on the values instead of repeatedly managing array positions.

25. Adding and Removing Items from Arrays

After understanding how to create and access arrays, I wanted to learn how to modify them. PHP provides built-in array functions that allow us to add new elements or remove existing elements from different positions.

1. array_push() — Adding Elements at the End

The array_push() function adds one or more elements to the end of an existing array. 

<?php

$skills = ["HTML", "CSS"];

array_push($skills, "JavaScript", "PHP");

print_r($skills);

?>

After using array_push(), JavaScript and PHP are added after the existing elements.

2. array_pop() — Removing the Last Element

The array_pop() function removes the last element from an array and returns the removed value. 

<?php

$skills = ["HTML", "CSS", "JavaScript", "PHP"];

$removedSkill = array_pop($skills);

echo "Removed: " . $removedSkill;

print_r($skills);

?>

In this example, PHP is removed from the end of the array.

3. array_unshift() — Adding Elements at the Beginning

The array_unshift() function inserts one or more elements at the beginning of an array. 

<?php

$skills = ["CSS", "JavaScript", "PHP"];

array_unshift($skills, "HTML");

print_r($skills);

?>

Here, HTML becomes the first element of the array.

4. array_shift() — Removing the First Element

The array_shift() function removes the first element from an array and returns the removed value. 

<?php

$skills = ["HTML", "CSS", "JavaScript", "PHP"];

$removedSkill = array_shift($skills);

echo "Removed: " . $removedSkill;

print_r($skills);

?>

In this case, HTML is removed from the beginning of the array.

Understanding the Difference

Function Purpose Position
array_push() Adds elements End
array_pop() Removes an element End
array_unshift() Adds elements Beginning
array_shift() Removes an element Beginning

One more thing I learned is that array_shift() and array_unshift() reindex numeric keys in an indexed array. Associative string keys are preserved.

What I learned:

These four functions make it easier to manage changing information. For example, I can add new skills, remove an outdated item, or update a list without creating a completely new array.

26. Joining and Splitting Strings with implode() and explode()

While working with arrays and strings, I came across two useful PHP functions: implode() and explode().

Their purpose is connected, but they perform opposite operations. One converts an array into a string, while the other converts a string into an array.

1. implode() — Converting an Array into a String

The implode() function joins all elements of an array into a single string using a separator of our choice. 

<?php

$skills = ["HTML", "CSS", "JavaScript", "PHP"];

$result = implode(", ", $skills);

echo $result;

?>

The output becomes: 

HTML, CSS, JavaScript, PHP

Here, the comma and space are used as separators between the array elements.

2. explode() — Converting a String into an Array

The explode() function performs the opposite operation. It splits a string into an array whenever it finds the specified separator. 

<?php

$subjects = "HTML,CSS,JavaScript,PHP";

$result = explode(",", $subjects);

print_r($result);

?>

The string is divided wherever PHP finds a comma, and each separated part becomes an element of the resulting array.

Understanding Both Functions Together

<?php

$subjects = ["HTML", "CSS", "JavaScript", "PHP"];

// Array to String
$stringData = implode(" | ", $subjects);

echo $stringData;

echo "<br>";

// String to Array
$arrayData = explode(" | ", $stringData);

print_r($arrayData);

?>

In this example, I first joined the array elements into one string and then split that string back into an array using the same separator.

My understanding:

implode() is useful when I need to combine array values into a readable string, whereas explode() is useful when I need to separate a string into individual parts.

27. Generating Random Numbers and Working with Date and Time

While exploring PHP's built-in functions, I discovered that PHP provides ready-made functions for performing common tasks. Two useful examples are generating random numbers and working with dates and time.

Understanding the rand() Function

The rand() function generates a pseudo-random integer. We can provide a minimum and maximum value to define the range of numbers. 

<?php

$number = rand(1, 100);

echo "Random Number: " . $number;

?>

Every time this program runs, PHP can generate a different number between 1 and 100, including both limits.

I also learned that rand() is suitable for simple random-number tasks, but it should not be used for security-sensitive values such as passwords or authentication tokens. For those situations, PHP provides random_int().

Understanding Date and Time in PHP

Websites often need to display dates and times. For example, a website may show when a visitor submitted a message, when an account was created, or when a particular record was updated.

PHP provides the date() function to format a date and time into a readable string.

Using the date() Function

<?php

echo date("d-m-Y");

?>

The format characters tell PHP which parts of the date should be displayed.

Format Meaning Example
d Day of the month 18
m Month in numbers 11
Y Four-digit year 2026
h 12-hour format 11
H 24-hour format 23
i Minutes 45

A AM or PM PM

Displaying the Current Date and Time

<?php

date_default_timezone_set("Asia/Kolkata");

echo "<br>";

echo "Current Time: " . date("h:i:s A");

The date_default_timezone_set() function sets the timezone used by PHP's date and time functions in the current script. Here, I selected the Indian timezone, Asia/Kolkata.

Understanding the time() Function

The time() function returns the current Unix timestamp. A Unix timestamp represents the number of seconds elapsed since January 1, 1970, at 00:00:00 UTC. 

<?php

echo time();

?>

Understanding the strtotime() Function

The strtotime() function converts many human-readable date and time expressions into a Unix timestamp. We can then format that timestamp using date(). 

<?php

date_default_timezone_set("Asia/Kolkata");

echo date("d-m-Y", $tomorrow);

?>

Here, PHP calculates the timestamp for tomorrow and displays it in day-month-year format.

What I understood:

PHP can work with dates and time on the server side. The displayed result depends on the timezone configured for the PHP script or server; it does not automatically use the visitor's browser timezone.

28. Receiving Form Data with the $_POST Superglobal

After learning variables, conditions, loops, functions, and arrays, I wanted to understand how a website receives information from its visitors.

For example, when someone fills in a contact form with their name and message and clicks the Submit button, how does the server receive that information?

This is where HTML forms and PHP work together.

Understanding an HTML Form

An HTML form collects information from the user. The method attribute specifies how the browser sends the form data to the server.

One commonly used method is POST. 

<form action="process.php" method="POST">

    <label for="username">Your Name:</label>

    <input type="text"
           id="username"
           name="username"
           required>

    <button type="submit">Submit</button>

</form>

Here, the form sends its information to a PHP file named process.php.

One important thing I noticed is the name attribute. The browser uses this name as the key through which PHP can access the submitted form value.

Understanding the $_POST Superglobal

PHP provides a special predefined associative array called $_POST. It contains form data submitted using the HTTP POST method.

It is called a superglobal because it is available throughout the PHP script without needing to declare it as a global variable inside every function.

Receiving Submitted Information

Let's create a file named process.php to receive the submitted name. 

<?php

if ($_SERVER["REQUEST_METHOD"] === "POST") {

    $username = $_POST["username"] ?? "";

    $username = trim($username);

    if ($username !== "") {

        echo "Welcome, " .
             htmlspecialchars($username, ENT_QUOTES, "UTF-8");

    } else {

        echo "Please enter your name.";

    }

}

?>

Let's understand the important parts of this program:

  • $_SERVER["REQUEST_METHOD"] helps us check whether the current request was sent using POST.
  • $_POST["username"] accesses the submitted value using the form field's name.
  • ?? "" provides an empty string if the expected POST key is missing.
  • trim() removes unnecessary whitespace from the beginning and end of the submitted string.
  • htmlspecialchars() converts special HTML characters into safe representations before displaying user-submitted text in HTML.

Understanding the Difference Between GET and POST

During this learning process, I also came across another commonly used form method: GET.

GET POST
Data is commonly included in the URL as query parameters. Data is sent in the HTTP request body.
Useful for searches and retrieving information. Commonly used for submitting or sending information.
Submitted values may appear in browser history and URLs. Submitted values do not normally appear in the URL.
Accessed using $_GET. Accessed using $_POST.

I also understood that POST does not automatically make information secure. Sensitive information still needs HTTPS, proper validation, and appropriate security measures.

Connecting PHP with a Real Website

This concept helped me understand how PHP can be used in practical projects. For example, a portfolio contact form can collect a visitor's name, email address, and message. PHP can receive and validate those values and then save the information into a MySQL database.

This is one of the ways frontend and backend development work together to create a functional website.

My learning observation:

HTML creates the form that visitors interact with, while PHP handles the information received by the server. This made the connection between frontend and backend development much clearer to me.
